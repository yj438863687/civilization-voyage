# 文明航程 Civilization Voyage

当前版本保留3D岛屿人物、浮动字幕与水上互动，补齐四时代的中国／世界故事、24站图片背景、原创配乐、船只改造和船员换装。每条航线按年代展开，最后由适合该时段的人物回顾实际选择。见[时间线、史料与验证说明](docs/history-music-refit.md)。

开船到岛旁按E进入故事，按Escape返回；按B打开船坞。补给用于整修船体，人心用于解锁船员行装。选择的代价、合作与支援会延续到后续章节。

## 启动基础版

```sh
chmod +x scripts/dev.sh
./scripts/dev.sh
```

浏览器打开 http://127.0.0.1:5173  
API 默认 http://127.0.0.1:8010（本机 8000 常被占用）。无密钥也可跑测试航程、交易和日志。

走一遍：选择时代 → 内海（中国）或外海（世界）→ 依次完成两座岛与最后一站 → 回港总结并落印 → 下一时代。刷新后会恢复上次航程。

四个时代有对应船型；船坞可免费预览各级外观，购买后会改变海上的实船。

## 四个时代

农业、工业、信息、人工智能，各含中国与世界两条历史航线。核心问题始终是：获得技术能力以后，怎样安排资源、劳动与共同生活？原型中的模型接口仍可单独配置；不是进入故事的前提，当前主线没有新增船员代问或付费线路剧情。
