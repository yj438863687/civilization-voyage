# KayKit — Character Pack: Adventurers (1.0)

- 作者：Kay Lousberg（kaylousberg.com）

- 授权：CC0（作者 README 原文：Free for personal and commercial use, no attribution required. CC0 Licensed）
- 用途：本项目中所有人物（岛上的人、岸上的历史人物、玩家）的身体与动作。
  时代特征由项目自己的帽子与手持物提供，挂在模型的头骨与右手骨上。
- 模型自带的刀、斧、盾、法术书等道具在加载时一律隐藏。
