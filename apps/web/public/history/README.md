# 历史背景配图

本目录提供阅读页使用的本地 JPEG。图片已缩放、转换为 JPEG；各张图片保留 [ATTRIBUTION.json](ATTRIBUTION.json) 所列的原始许可或公有领域状态，**不适用项目代码的 MIT 许可**。再使用或分发时须逐图查看作者、来源、许可链接与相应要求。

展示元数据及图注位于 `../../src/world/historyMedia.json`，界面可展开「图片来源与授权」。来源页面与作者记录在 `ATTRIBUTION.json`；更新素材时同步两处记录与本地文件，保留加工说明。

图注描述图片实际内容，并指出与故事的年代、地点或语境差异。现代都江堰照片不是传说时代影像；吉尔苏泥板晚于乌鲁克故事；20 世纪电键不是 1871 年上海设备；1918 年詹天佑照片晚于京张铁路通车；普通棋盘不是 AlphaGo 比赛现场；天河二号不是未来港口。画像、版画、器物与设施照片只作背景材料，不代表创作互动场景的实拍或考古复原。

历史背景出处另存于 `../../src/world/history.ts` 的各场景 `source`。图片来源不能替代历史论据，也不能证明故事人物、对话或抉择真实发生过。扩展规则见 `../../../../docs/design/HISTORY_ISLANDS.md`；新增图片后运行仓库根目录的 `node scripts/test-history.mjs` 检查引用与本地文件。
