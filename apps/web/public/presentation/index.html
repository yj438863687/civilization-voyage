本版故事主线

以历史改造前c1a8fe8为互动基线，与后续历史改进合并。

  1. 选择时代与中国或世界航程，直接出海。
  2. 登岛后，玩家直接与当地人物交谈，点“接着问”继续。
  3. 查看配图与出处，完成小游戏，再决定成果如何使用。
  4. 补给与人心体现眼前航行和共同生活的取舍，前章影响后章。
  5. 到港由适配人物回顾三章；补给改船，人心达标换船员行装。

人物台词为创作；模型只是可选资料工具。构建与规则检查通过，本版未运行新的浏览器演示，仍待体验验收。
