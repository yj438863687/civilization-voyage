# v09 · 恢复人物、场景与画面字幕

本版修正v08只恢复对话内容、没有恢复原版呈现的问题。

人物与造景重新使用原3D绘制链路，历史图片标牌缩小为岛边补充；危机里的村子与工地恢复。进入故事先看原场景与逐句字幕，不默认打开不透明阅读面板。按“历史图片与背景”可看配图与来源，再回到人物对话。终点恢复岸上人物独白，回顾内容仍适配本航程。

## Demo操作脚本（未录制完整航程）
1. 启航，沿海图靠近第一岛，按E见岛上人物。
2. 看原3D人物与场景，对话在画面底部逐句出现；空格或“接着问”继续。
3. 也可先点岛边“图片故事”独立入口，查看配图与出处，再收起返回航行；不扣补给、不增加人心、不推进章节。交谈中仍可打开“历史图片与背景”查看。
4. 进入原小游戏并作安排，结果回到场景字幕，确认后才结算。
5. 继续后两章，到港听适配人物回顾；补给、人心与升级规则沿用。
