# v07 · 故事与船员融合初版

本版暂停 Demo 运行和录制。没有制作新的演示视频，也没有把旧录像当成本版验收。

## 操作脚本（待实机体验验收）
1. 打开文明航程，选择农业、工业、信息或人工智能时代。
2. 启航页选择内海中国或外海世界；分别点「听大副说」「听二副说」，再出海。不需要先接模型或购买筹备线路。
3. 靠近岛屿进入原有故事。故事现场可选择「请大副同行」或「请二副同行」，再点现场或人物，听问题与回应。
4. 完成原有小游戏，决定技术怎样用于共同生活；确认前可查看「船员陪同留下的见闻」。确认后写入本章状态，沿原海图去下一站。
5. 连续完成三章，到港听适配本航程的人物回顾。已保存的见闻会出现在相应章节下。
6. 按需进入「船上书房 · 资料与模型」整理来源、使用 Agents、共建港城；模型接入是辅助能力。没有密钥时，剧情对话明确为创作，并非模型回复。
