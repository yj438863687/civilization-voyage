## 从碎片到行动，再回到问题

【AI推荐待确认｜推演；出处：CHI1293 W3–4 p09–10 / 作业2 p02】建议把一个可回看的成果表达为：**我的问题 → 用过的材料 → 尚存的分歧 → 我采纳的解释与理由 → 港口中的行动 → 结果与修订**。这是文档层的内容结构，不预设数据库字段或端点。任何一步都可以承认证据不足；最终采纳印记录责任主体，不是知识终审证书。

【AI推荐待确认｜推演；出处：CHI1293 W1–2（和而不同）/ W3–4 p15；项目锚点：FRAMEWORK.md】低成本路线与高成本路线表示探索深度和步骤的差别，不是对错之分；具体成本尚须真实服务接入后独立说明。不能把较多步骤的创作建议伪装成已经发生的模型调用或实际费用。

【AI推荐待确认｜推演；出处：CHI1293 作业2 p02–03】互鉴交互让玩家依次指认接收方主动选择的证据、在地改造的差异、延续进入传统的证据。每项可判断“满足 / 不满足 / 证据不足”，并说明为什么。不能因勾完三个按钮宣布历史成立；只有三项证据都支持时，才提出“按作业2判准可判为互鉴”的有范围判断，仍保留异议。

【AI推荐待确认｜推演；出处：CHI1293 作业2 p02；W3–4 p15】真实历史的“持久融入”依靠跨时段材料；单次游戏最多让人体验一种形成或中断的过程。模拟里延续了几轮只构成【推演/创作】的内部结果，不升级为历史证据。若缺后期材料，应停在“发生交换，互鉴证据尚不足”；若材料显示强制接受，应明确说明主动选择条件不满足。

【AI推荐待确认｜推演；出处：CHI1293 W3–4 p13–15 / W5–6 p04】文化碎片的说明至少回答：它是什么材料、来自哪里、经过谁的选择或翻译、记录了谁、遗漏了谁、能支持哪一项判断。默会知识不能被录入穷尽；允许“需要实践者说明”成为下一步，而不是把没有数字记录的人判为没有知识。

## 教练按状态给一个动作

以下句子均为【AI推荐待确认｜创作；出处：CHI1293 W3–4 / 作业2；产品转译】，不要求玩家认识哲学术语。

| 当前状态 | 下一步条 | 完成后看见什么 |
| --- | --- | --- |
| 还没有问题 | “先写下你想弄清的一件事。” | 问题进入任务草稿，可改写 |
| 不会写任务 | “选一个问题，请船员帮你缩小范围。” | 草稿仍由玩家确认，不能悄悄替玩家定题 |
| 船员尚未接入 | “船员尚未接入。先写问题，或到通讯台配置。” | 明确未接入；没有假回复或假用量 |
| 船员意见不同 | “先打开一处来源，看看他们为什么不同意。” | 同一问题的证据与分歧仍并存 |
| 准备选择路线 | “看清两条路线各查什么，再选一条。” | 所选范围与暂不核查的部分可回看 |
| 已出海，不知去处 | “朝海图上的目的港航行。” | 港口方向与当前任务相互对应 |
| 靠港并取得材料 | “打开这份材料，看看它能说明什么。” | 出处、性质、疑点在一起 |
| 只收集没有使用 | “选一份材料，用它说明你的港口安排。” | 材料与行动产生可检查的联系 |
| 正要采纳解释 | “还有疑点吗？写下理由，再决定是否落印。” | 可采纳，也可保留待查；不强迫盖真理印 |
| 行动后 | “看看谁受益、谁承担代价。要改一处吗？” | 允许修订并保留此前理由 |
| 材料不足 | “还缺一份证据。先把这项判断留待核实。” | 未完成的判断可以留在日志，不伪装通关 |

## 给后续实现者的验收情境

【AI推荐待确认｜推演；出处：CHI1293 W3–4 p10、p15 / W5–6 p04–06、p11】这些是人工走查情境，不表示本轮已实现或已测通过：

1. 两位船员都赞成一项无出处的主张，界面仍不将它标为史实；玩家能追问或暂缓。
2. 玩家选择较少步骤路线，仍能形成有边界的有效问题；不会被判为不重文化。较多步骤路线也能得出“证据不足”。
3. 玩家已有碎片但未使用，世界不会仅因收集数量宣布“知行合一”；教练能指向一个具体使用动作。
4. 港口安排提高剧情效率却遗漏远处劳动者时，玩家能看见该遗漏并说明取舍；不预先设定统一道德答案。
5. 玩家不采纳两位船员的建议，日志仍能记录自己的理由和疑点；再次出航可带着原问题修订。

【AI推荐待确认｜推演；项目锚点：FRAMEWORK.md / docs/handoffs/codex-to-grok.md / claude-to-grok.md】联调时另核对：当前接口是否支持所需记录与来源、未接入是否明示、真实用量与剧情资源是否分账、演示内容是否保留测试标记。缺能力就列为待实现，不能靠假生成、假核验或伪费用补齐；本轮不修改接口和业务逻辑。
