## 印章：内容性质与确认状态分开读

| 印章 | 含义与使用边界 |
| --- | --- |
| 【史实】 | 可被历史材料检验的主张；必须附具体材料、位置与核实记录。课程出现过不等于外部史实已核实。 |
| 【推演】 | 根据材料或概念提出的解释、条件判断与产品映射；交代依据和条件，不冒充已经发生。课程哲学主张也在此类，并加“课程主张/课程诠释”。 |
| 【创作】 | 原创台词、虚构情境与视觉意象；说明作者/生成性质，不作历史证据或未来预测。 |
| 【AI推荐待确认】 | 审议状态，可与前三类叠加；表示尚未获组员确认，不表示来源已经可靠。候选场景始终保留此标。 |

【AI推荐待确认｜推演】“史实候选·待核实”是本轮的编辑批注，**不是已通过的【史实】印**。此类内容不能作为确定事实进入 UI；核实不足时可以展示待核实问题，不能只删去“候选”二字。组员确认场景、玩家采纳解释、史实核验是三件不同的事，玩家落印不会把主张变真。

【AI推荐待确认｜推演】印章至少同时用文字、边框/形状与颜色表达，允许多种性质并存于一个成果中的不同段落；不能以整页一个“史实”覆盖其中的推演。既有设计中的“测试”“分歧”继续作为辅助标记，不能代替前三类。产品主张的印章和出处写在条目或表格行上；同一段落内的定义、易混点和禁忌共用该标记。同组同性质的短文案或意象表可在表前声明共用印章与出处；抽取单句交付时须一并带走，不得丢失。
