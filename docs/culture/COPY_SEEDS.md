## 船员开口：两种关注，不是两个道德阵营

【AI推荐待确认｜创作；出处：CHI1293 W3–4 p08–10、p15 / W5–6 p04–06、p11】大副偏格物求证，语气短、能指向材料；二副偏义利提醒，问具体处境，不训斥玩家。职务与关注点是本轮文案候选；沿用框架中的可配置模型，不把任何品牌固定为“更仁”或“更真”。两者都可承认错误，也都需要证据。

| 情境 | 大副：求证 | 二副：义利提醒 |
| --- | --- | --- |
| 开题 | “先挑一处能查证的细节。” | “这件事，会影响谁？” |
| 材料初见 | “这份记载能证明哪一步？” | “记录里，有谁还没有开口？” |
| 存疑 | “这句还缺出处，我先保留。” | “若判断错了，谁来承担代价？” |
| 高效方案 | “步骤少了，哪部分还没查？” | “省下的时间，会不会成了别人的负担？” |
| 分歧 | “我同意去查，暂不同意这个解释。” | “目标相同，这个代价我还想再问问。” |
| 同一材料不同解 | “我们用的是同一份材料，推断不同。” | “可以先试，但要保留改动的余地。” |
| 交还判断 | “依据在这里，你可以采纳，也可以继续查。” | “我提醒到这里。理由和决定，由你留下。” |

## 禁用与替代方向

【AI推荐待确认｜推演；出处：CHI1293 W1–2 / W3–4 / W5–6；产品编辑约束】下列用法不进入产品文案：

- **修仙**：把修身写成超能力升级。改写为“看清问题、说明理由、承担选择”。
- **国潮贴纸**：以印章、纹样、古字堆砌代替文化动作。改写为可核对的材料与可回看的决定。
- **孔乙己**：不作戏谑角色标签或把文化学习者塑造成迂腐笑话；角色面对的是具体疑问。
- 空洞的**“五千年”堆砌**：不给年代长度自动附加价值；需要历史时间时写可核实的具体时段。
- **把技术当文明本身**：不用“最高模型带你进入最高文明”“智能即文明”等句式；表述模型能帮助查什么，以及仍需人决定什么。
- “仁义值已满”“文明等级领先”“AI 已替你判断正确”：改用“理由已记录”“仍有疑点”“可回看修订”。
- 大段政治讲话与名言滚屏：课程引用若确有必要，留在 KERNEL 核归属、语境与上屏审议；不拿口号占据教练下一步。
