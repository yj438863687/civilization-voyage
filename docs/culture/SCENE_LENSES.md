# A / B / C：同一内核的三种处境

> 【AI推荐待确认】三个场景均为 **AI推荐待组员确认**，沿用 [SCENE_CANDIDATES.md](../design/SCENE_CANDIDATES.md)。本文件只提出文化透镜与交互候选，不改 `scenes/A.md`、`B.md`、`C.md`，不新增正式剧情或经济参数。下文“安排”“选择”均是待实现的演示任务建议。

## A · 宋元泉州港

【AI推荐待确认｜推演；出处：CHI1293 W1–2 / W4–5 p06、p10 / W5–6 p11–12 / 作业2 p02】**文化核心一句话**：货物靠岸以后，只有接收者能够选择、改造并延续所学，差异共处才可能进一步成为互鉴。和而不同不要求港口里的人变成同一种人。

【AI推荐待确认｜推演；出处：CHI1293 W4–5 p06 / W5–6 p11–12】**玩家要回答的文明问题**：一份货物已被接受，什么能证明其中的知识也被理解？港口怎样维持共同规则，同时容许不同语言、信仰与交易习惯继续存在？没有知识传播的成交也可以发生，不应被玩法自动写成互鉴。

【AI推荐待确认｜推演；出处：CHI1293 作业2 p02；W4–5 p06、p10】**互鉴进入交互**：玩家将材料分为“有货物流动证据”和“有知识/实践变化证据”，再为一个明确接收方指出主动选择、改造适应、持久融入各自的依据。船员可以争论同一材料究竟只证明使用，还是足以证明转化；玩家给出有范围的解释。缺其中一项就保留“交换已见，互鉴未证”，不按多宗教建筑数量结算。

【AI推荐待确认｜推演；出处：CHI1293 W3–4 p09 / W5–6 p11；项目锚点：SCENE_CANDIDATES.md】**行出来的成果**可以是一份由玩家说明理由的港口合作安排草案，标明共同规则、容许保留的差异与尚未听见的声音，再由新材料检验。它是现代产品中的【创作/推演】任务，不能题作“宋元港规复原”。

【AI推荐待确认｜史实候选·待核实；出处：CHI1293 W5–6 p12】泉州“多信仰并处”不能扩大成“从无冲突”。郑和、“所予多于所取”、玄奘与禅的关联均留在 KERNEL 的待核清单，不为本场景直接补成历史定论。

【AI推荐待确认｜创作；项目锚点：ART_DIRECTION.md】郑和/宝船在这里**只作通用船的气势概念**。宋元泉州与明代郑和分属不同时段；通用船随场景保留“概念设计，非考古复原”，不冒充本港当年的具体船体、尺度或装备。

## B · 集装箱改变港口

【AI推荐待确认｜推演；出处：CHI1293 W1–2（礼）/ W5–6 p04–06（义利）；项目锚点：SCENE_CANDIDATES.md】**文化核心一句话**：标准像礼一样使协作可预期，却须接受义的追问：效率的收益和转型的代价分别落在谁身上？这是文化类比，不宣称现代标准就是古礼的历史延续。

【AI推荐待确认｜推演；出处：CHI1293 W4–5 p06、p10–12 / W5–6 p04–06】**玩家要回答的文明问题**：当港口为统一尺度改变工作方式，谁有权制定标准，谁被要求适应？中介是在降低跨地协作的困难，还是用信息差把收益与代价隔开？“标准塑造文明”应落实为制度、劳动与日常生活的变化，不直接等同道德进步。

| 碎片类型与印章 | 用来追问什么 | 来源与核实任务 |
| --- | --- | --- |
| 【AI推荐待确认｜史实候选·待核实】尺寸规则、港口档案与转型记录 | 标准由谁协商，进入当地时改变了什么？ | CHI1293 W1–2 / 作业2 的分析透镜；集装箱史据候选文档所列研究与公开标准摘要另核，本课 OCR 不是集装箱史料 |
| 【AI推荐待确认｜史实候选·待核实】劳动、城市空间与长期变化材料 | 吊装之外，生活和机会怎样改变？ | CHI1293 W5–6 p03–06 的隐去劳动透镜；口述史须授权并核范围，不收录私人访谈原文 |
| 【AI推荐待确认｜推演】同一安排下不同参与者的收益与负担对照 | 什么被计入“效率”，什么没有被计入？ | CHI1293 W5–6 p06；假设逐项列明，未取得统计不伪造真实降本比例，不制定经济参数 |
| 【AI推荐待确认｜创作】货物流与信息流分离的示意 | 标准让箱子通行，是否也让人彼此理解？ | 由 CHI1293 W4–5 p06、p10 转译；不把现代中介直接写成“安息再世”或固定反派 |

【AI推荐待确认｜推演；出处：CHI1293 作业2 p02 / W5–6 p06】**互鉴进入交互**：以一个有材料的接收地区为单位，分别找“为何采用”“怎样改变当地流程”“何以持续成为惯例”的证据。若标准由外力强制执行，主动选择条件可能不满足；若只是使用相同箱型，也不足以证明互鉴。允许结论是“技术传播成立，互鉴条件不足”，不能把统一标准天然美化为自愿合作。

【AI推荐待确认｜推演；出处：CHI1293 W3–4 p09 / W5–6 p04–06】**行出来的成果**可以是一项标准采用安排的说明：玩家保留何种地方做法、照顾何类转型负担、哪些异议仍未解决。求证船员检查档案与比较口径，义利船员追问工人和被排除者；最终由玩家决定和修订。禁止做成装箱速度越快、文明分越高的竞速题。

## C · 海平面上升后的漂浮港

【AI推荐待确认｜创作；概念出处：CHI1293 W1–2（生生）/ W5–6 p11、p13；项目锚点：SCENE_CANDIDATES.md】**文化核心一句话**：迁徙带走的不只是物件，还要给后人继续生活与改写文化的条件。漂浮港是创作，不是对某地未来的预测。

【AI推荐待确认｜推演；出处：CHI1293 W5–6 p13、p15 / W1–2】**玩家要回答的文明问题**：空间改变时，什么文化值得携带，由谁决定？今天的安排是否把维护和资源负担留给了不能发言的后代？涟漪扩向时间之“宙”，不能只让眼前多数人的偏好主宰全部未来。

| 碎片类型与印章 | 用来追问什么 | 来源与核实任务 |
| --- | --- | --- |
| 【AI推荐待确认｜推演】科学评估中的条件情景、范围与不确定性 | 在什么条件下讨论适应，而非宣称未来必然如此？ | 项目候选文档指向 IPCC 等材料，尚待选定具体章节、情景与年份；CHI1293 大纲 W12 为待讲，不能冒称已讲过气候专题结论 |
| 【AI推荐待确认｜史实候选·待核实】已有适应规划或漂浮建筑案例 | 现实做过什么，哪些限制仍在？ | 依候选文档另核工程状态与公开来源；不能把概念原型说成已建成城市 |
| 【AI推荐待确认｜创作】携带技艺、语言、仪式或共同记忆的清单与虚构居民意见 | 带走物件后，是否还有人会做、愿意教、可以改变？ | CHI1293 W3–4 p13–15；清单与角色均为演示创作，不虚构真实受灾社区的证言 |
| 【AI推荐待确认｜推演/创作】当前选择与后续维护的对照记录 | 谁承担下一代的代价，是否仍保留修订权？ | CHI1293 W1–2 / W5–6 p13；演示内部后果不作环境、工程或人口预测 |

【AI推荐待确认｜推演；出处：CHI1293 作业2 p02 / W3–4 p13–15 / W5–6 p13】**互鉴进入交互**：不同虚构社区提出可带入港口的实践，玩家查明接收方是否自愿、如何适应新的生活条件，再看它是否被持续使用和传授。一次迁入不表示持久融入；演示可分阶段展示延续或中断，但一切结果保持【创作】，只练习判准，不充当作业2要求的真实历史案例。

【AI推荐待确认｜创作；概念出处：CHI1293 W3–4 p09、p13 / W5–6 p13、p15】**行出来的成果**可以是一份带修订入口的文化携带方案：不只选物件，也说明谁能继续实践、谁能学习、后人能否改写。求证船员指出情景条件，义利船员提醒缺席者与后人；玩家可以改变方案。禁止将文化做成限重行李的价值排行，不把“保存得一模一样”设为唯一好结局。

【AI推荐待确认｜推演；出处：CHI1293 W1–2 / 大纲】生态守护的概念依据来自前段已讲材料；W12 生态专题、W13 数字与 AI 文明仍为**大纲待讲**。后续新课可能改变透镜，不以本轮创作替未来课程预先作答。
