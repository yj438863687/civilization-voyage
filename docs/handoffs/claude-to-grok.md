## 2. 必须遵守的设计决定

### 2.1 通用船外形（用户指示：更霸气，参考郑和下西洋宝船）

船是产品的标志物，**以下为必守项**，细则与比例表见 [ART_DIRECTION.md § 通用船外形](../design/ART_DIRECTION.md)。

1. **意象：明初宝船 / 福船气势**——宽体、高艉楼、多桅硬帆、方形平艉、外张舷弧。不做欧式尖艏、不加炮门、不加西式船首像。
2. **比例用 4 : 1 : 2.5**（长 : 最大宽 : 主桅甲板以上高）。艉楼占船长后 1/4，**三层阶梯后退**，是整船最醒目的轮廓；艏楼只在前 1/10、一层、低矮。
3. 6–8 桅硬帆（横杆帆），主桅居中偏前，帆面有折线、可分层收帆；船尾中央大舵；艏部两侧**船眼**（白底墨瞳，不发光）。
4. **材质色走 `--cv-ship-*`**：墨木船体、朱漆楼层与栏杆、铜金配件、米色硬帆、`--cv-ship-banner` 旗帜点缀。不要在材质文件里散写色值。
5. **船上朱漆是材质，界面朱砂是“用户落印”**。3D 里禁止用朱漆色做可交互高亮。
6. **船是通用容器**：换场景只换 `--cv-ship-banner`、旗帜图案、帆上点缀色、舷窗场景光，以及木色深浅一档。**结构、比例、楼高、桅数、船眼位置不变。**
7. **镜头**：启航为四分之三侧影、略俯 8–12°、距离约 1.8L，**整船入画、艉楼不被裁切**；航行为斜后上方（方位 30–40°、俯 15–20°、距离 1.2–1.5L），船占画面宽约 1/3。减少动态时直切机位，不做环绕与推镜。
8. **声明必须随模型与概念图一起出现**：概念设计，**不是考古复原**，不冒充任何一艘历史具体船只；宝船原始尺度学界有争议，比例是视觉建议而非历史尺寸。
9. **不画未授权的文物纹样**。船体装饰用几何化、低细节的铜件与栏杆，不复制出土器物或他人复原图的图案。

### 2.2 界面与场景

这些是方向性的，请按此实现；如认为有冲突，先在 PR 里提出，不要单方面偏离。

1. **通用驾驶舱 + 场景皮肤分离。** 船舱、海图桌、HUD、面板、印章、状态、字体、基础色都不随场景变。场景只通过根节点 `data-scene="A|B|C|test"` 覆盖 `--cv-scene-*` 变量（accent、天空、雾、水色、光色、场景标签）。换场景不得要求改任何通用组件。
2. **只用语义变量。** 组件写 `var(--cv-surface-1)`、`var(--cv-text-muted)`、`var(--cv-state-* )`，不写死色值、不直接引用 `--cv-ink-*` 原始色阶。
3. **禁止**：`backdrop-filter: blur`、外发光边框（除焦点对象）、多层透明叠加卡片、霓虹渐变背景、装饰性仪表盘。
4. **朱砂主按钮一屏最多一个**，只给“用户做决定”的操作：确认航程、启航、采纳解释 / 提交成果、再次出发。
5. **两本账物理分开**：真实模型用量（海色、等宽数字、未接入时虚线边 + “尚未接入”）与剧情资源（铜色）上下分块，不并排、不合成一个“余额”。测试资源必须带“测试”印章 + 斜纹，绝不写成 HMT。
6. **未接入 = 显式未接入**。没有真实接口时显示“尚未接入”，不显示 0、不显示预计为实际、不出现假回复。
7. **内容性质印章**（史实 / 推演 / 创作 / AI 推荐待确认 / 测试 / 分歧）必须文字 + 颜色 + 边框样式三重区分，不能只靠颜色。史实必须有出处，无出处不得标史实。
8. **状态 = 颜色 + 图标 + 文字 + 下一步操作**，七种状态按 DESIGN_SYSTEM §7 实现。失败显示原因原文（去除凭据）与重试，不静默重试、不伪装成功。
9. **保留分歧**：船员不同意见并排展示并标“分歧”，不合并成一条结论，不把多个模型赞同当作事实证明。
10. **可观察事件而非隐藏推理**：只展示开始 / 调用工具 / 工具结果 / 引用材料 / 完成 / 失败。
11. **一个 3D 画布贯穿全程**，页面切换靠镜头 + 面板，不整页重载世界；面板打开时 3D 压暗但不卸载。
12. **减少动态**：读 `prefers-reduced-motion`，并提供应用内开关（开关优先）；关闭 C 类装饰动效、B 类镜头改直切；不得隐藏任何信息。
13. **对比度**：正文 ≥ 4.5:1，HUD 叠 3D 必须有 `--cv-hud-scrim` 底板。
14. **不伪造素材**：没有授权素材时用体块、剪影、海图符号 + “素材待补”标记，不复原具体真实建筑与遗址。

## 3. 允许前端按实际运行调整

- 具体像素、面板宽度、HUD 缩放比例（保持变量与层级关系）。
- 面板滑入的具体 easing，只要不超过规定的时长上限（camera 1.2s，其他见 tokens）。
- 断点位置的微调（当前 sm<640 / md 640–1023 / lg 1024–1439 / xl≥1440）。
- 罗盘、刻度等仪器的具体画法，只要不用发光与模糊。
- 3D 相机偏移、FOV、跟船阻尼系数（MOTION 给的是建议值）。
- 字体子集化方式与加载策略（必须有系统字体回退且不阻塞首屏）。
- 组件拆分方式、状态管理、事件流转——设计上只约束“呈现什么”和“不能隐藏什么”。

## 5. 桌面与手机主要布局

**桌面（≥1024）**
- 3D 全屏底层；HUD 四角（左上任务、右上两本账、左下罗盘、右下图标操作、正上场景标签）。
- 驾驶舱：左 88px 船员席位 / 中对话 / 右 360px 航程任务卡。
- 航线：海图中部 + 右 480px 面板。
- Agents 协作：3D 场景 + 右 480px 任务面板。

**平板（640–1023）**：驾驶舱右栏收为底部抽屉；航线面板收为底部抽屉。

**手机（<640）**
- HUD 合并为顶部一条（任务 + 资源缩略），罗盘 88px，右下操作为“更多”。
- 船员席位顶部横排；任务卡底部抽屉，把手显示草稿状态；输入框固定底部。
- 航线页海图占顶部 40%，两条航线为可滑动对比卡。
- Agents 协作：3D 上半屏，面板下半屏三标签（步骤 / 事件 / 选择），等待选择时自动切到“选择”。
- 所有触控区 ≥ 44px，留 `safe-area-inset`。

## 6. 3D 视角与 UI 覆盖关系

| 页面 | 相机 | UI 覆盖 |
| --- | --- | --- |
| 启航 | 四分之三侧影（正面偏前 20–30°），俯 8–12°，距离约 1.8L；整船入画、艉楼不裁切 | 左侧文字与按钮覆盖 3D，右侧卡片带 opacity 底板 |
| 驾驶舱 | 舱内固定，舷窗为洞 | 面板不透明覆盖大部分画面，3D 只作氛围 |
| 航线 | 俯视海图桌 | 面板覆盖右侧 480px，海图航线为 3D 或正交投影绘制 |
| 航行 | 斜后上方跟船：方位 30–40°，俯 15–20°，距离 1.2–1.5L，弹簧阻尼；船占画面宽约 1/3 | HUD 四角，中央留空 |
| 港口 / 场景 | 推近 → 场景工作视角 | 材料/任务面板右侧覆盖 |
| 反思 | 舱内对准日志 | 日志纸面为主体，3D 仅底衬 |

- 世界标签（港口名、碎片纸签）随 3D 投影，可被遮挡，不穿透地形显示。
- 焦点对象（等待选择的海图节点、当前碎片）可以用 `--cv-shadow-lamp`，单屏最多一处。
- 3D 渲染循环：有航行或动画时常规渲染；减少动态 / 低端设备时按需渲染。

## 7. 与后端的边界（提醒）

- 本目录不含任何端点定义。真实用量、预算、任务事件、片段与出处的数据结构以 Codex 维护的接口定义与生成类型为准。
- 设计只假定存在：任务步骤与可观察事件、两本账的独立字段、材料出处字段、性质标记字段、未接入状态字段。字段缺失时显示“尚未接入 / 出处待补”，不前端编造。
- 凭据输入框只在前端收集并交给配置入口，不回显、不写日志、不进导出文件。

### 9.3 印章控件

| 项 | 规格 |
| --- | --- |
| 落印 | 按住 600ms；松手取消；满后印落下（MOTION A 类“落印”已更新） |
| 理由为空 | 印为空心描边、`aria-disabled`，旁边“写下理由，由你落印。” |
| 印面 | 朱砂 `--cv-mark-adopt`；文字“采纳 · 疑点 n”（n 为任务卡/解释上未关闭的疑点数，没有该数据就只写“采纳”，**不编数字**） |

| 键盘 | 聚焦后按住 Space / Enter 同样 600ms |
| 适用 | 确认航程、采纳解释、提交港口安排。启航（`按此航线启航`）仍是普通朱砂按钮，不必按住 |

### 9.4 3D 氛围（不改船，不加灯数上限）

现值：`SHIP_L = 20`，海面雾 `uFogNear 55 / uFogFar 170`（≈ 2.75L / 8.5L）。**雾不改。**

| # | 项 | 常数名建议 | 值 | 验收 |
| --- | --- | --- | --- | --- |
| 1 | 舷窗望港 | — | 驾驶舱前窗（`cockpit` 机位）朝向当前目的港；港口码头灯 3–5 盏可见，作暖色小点穿过雾 | 坐在桌后能看见“要去的地方有灯” |
