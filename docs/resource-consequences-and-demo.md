# 资源后果与实录 Demo v3

主线仍是原人物、场景、字幕与水上任务；没有引入模型大副或二副。技术增加行动能力，补给维持船，人心维持共同使用技术的人。

## 资源与结局

- 补给 ≤15：航速降低30%；人心 ≤20：此前合作带来的 +3 支援暂停。
- 任一资源归零：立刻停航，不能继续触发故事、自动航行或按 Escape 绕过。人心归零时船员离开甲板，船长仍在。
- 可以接受代价返航：得分扣200（最低0），连击清零。补给耗尽恢复到35，耐久扣20、船体整修降一级；人心耗尽恢复到30、行装降一级。双归零叠加，等级最低0。保留故事选择，回出发水域；重复回调和刷新不重复扣款。
- 也可以结束：分别记录「断炊的航程」「无人响应的号令」「空船回航」及原因。结束存入航程和反思记录，刷新仍保留，不能直接续航绕过。
- 正常落印也会评价资源：满舱而独行、同行却难以为继、共同远行、重整后的共同远行等。以落印时、靠港补充前的资源评价；原有港口补充仍保留，并明确展示评价时余额。
- 旧存档缺少 setbacks 时按0加载；没有数据库结构迁移。

## 实际视频制作

录制脚本 scripts/capture-demo.mjs 使用隔离 API 8015 和演示存档。预置资源、位置与之前完成的章节；镜头中的操作、结算、付费重整与坏结局由真实游戏响应，没有注入结果。录制并非连续通关，不能声称全路线人工完成。

8段镜头：开场航行、内外海与双语、图片背景和岛上交互、真实升级、断炊与重整、人心归零并结束、正常回港落印、未来船型。

游戏 WebAudio 独立录音，用画面色块与5kHz校准脉冲对齐，校准段剪除。Edge TTS合成中英文旁白；脚本发送的是公开演讲文案，不含存档或用户信息。后期包含章节图形、逐词时间字幕、声音混合与淡入淡出，旁白较长时停留尾帧。视频持续标注实际游戏、预置存档、剪辑和合成旁白。不是未经剪辑的实时全程演示。

产物：1920×1080、30fps、H.264/AAC MP4，中英文各一份，另附字幕、章节和制作元数据。English主讲PPT与中文理解PPT各22页，含可编辑文字、讲稿及视频；A–E另有分讲PPT。PDF中的视频是封面，播放请用PPT或MP4。

复现顺序：启动隔离前后端 → scripts/capture-demo.mjs → scripts/voice-demo.py → scripts/edit-demo.py → scripts/build-pitch-v3.py。Playwright路径、浏览器路径通过 VOYAGE_PLAYWRIGHT_MODULE 与 VOYAGE_BROWSER_EXECUTABLE 配置；默认正式API不会参与录制。
