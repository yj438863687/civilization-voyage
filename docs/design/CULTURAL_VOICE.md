# 文化语气：先让人会走，再让人愿意想

> 【AI推荐待确认｜创作】本文件是界面文字的语气规范与可上屏短句库，由视觉负责人在 Codex 的 [COPY_SEEDS.md](../culture/COPY_SEEDS.md)（分支 `docs/cultural-kernel`）基础上筛选和润色。所有短句均为**产品原创**，不是假托古人的台词，也不是课件逐字引文。文化依据：CHI1293 W1–2 / W3–4 / W4–5 / W5–6 / 作业2；逐组另列。上屏前仍待组员确认。
>
> 配合阅读：[ART_DIRECTION § 文明内核如何被看见](ART_DIRECTION.md#文明内核如何被看见)。那一节说“光和手势怎么做”，本文件说“字怎么说”。字是最后一层，能用光和动作表达的，就不用字。

## 一、总语气

像一位**站在海图桌边、手里拿着铅笔的老水手**：话少，说具体的事，把笔递给你。

| 要 | 不要 |
| --- | --- |
| **短**：一屏的教练句一句话，≤ 20 字为宜 | 一段说明讲完全部规则 |
| **具体**：说动作和对象（“打开这份材料”“写下理由”） | 说美德和境界（“践行仁义”“提升修养”） |
| **平**：句号收尾，不用感叹号，不用“哦/呢/啦” | 热情营销腔、古装腔、文言腔 |
| **你**：直接对玩家说“你”，船员互称职务 | “亲”“少侠”“船长大人” |
| **承认不知道**：“还没查清”“证据不足”是正常句子 | 用含糊话掩盖缺口 |
| **把决定交还**：结尾落在“由你”上 | “AI 已为你判断”“推荐答案” |

标点：全角中文标点；界面中引用按钮名用「」（与现有前端一致）；数字用阿拉伯数字。

## 二、教练（coach 下一步条）

【AI推荐待确认｜创作；出处：CHI1293 W3–4 p09–10、p15 / 作业2 p02；流程依据：FRAMEWORK.md / APP_MAPPING.md】

**口吻**：指路，不评价人格；不代船员发言；分歧未决时只指向证据，不催“好人答案”。每次只给与当前状态相符的**一句**。

**结构**：`动作 + 对象`，必要时 `，再 + 下一个动作`。不超过两个动作。

| 状态 | 上屏短句 | 润色说明 |
| --- | --- | --- |
| 第一次进入 | 先写下你想弄清的一件事。 | 保留种子原句 |
| 不会开始 | 选一个问题，请船员帮你缩小范围。 | 保留 |
| 船员尚未接入 | 船员尚未接入。先写问题，或去通讯台。 | “到通讯台配置”→“去通讯台”，更短 |
| 意见不同 | 先看来源，再听他们各自的理由。 | 保留；比“打开一处来源”更有节奏 |
| 选航线 | 看清两条路线各查什么，再选。 | 删“一条”，收短 |
| 进入海域 | 朝海图上的目的港航行。 | 保留 |
| 靠港取得材料 | 打开这份材料，先看它从哪里来。 | 合并两条种子 |
| 只收集未使用 | 选一份材料，用它说明你的安排。 | 知行合一的核心一句，必须有 |
| 等待采纳 | 写下理由，由你落印。 | 保留；与印章控件的空心状态同句 |
| 行动后 | 看看谁受益、谁承担。要改一处吗？ | 删“代价”，留节奏 |
| 证据不足 | 这处还没查清，先留个问号。 | 两句合一 |
| 回顾 | 这次求快时，有没有漏查什么？ | 保留 |
| 再出发 | 带上没解决的问题，再走一程。 | “尚未”→“没”，更口语 |

## 三、船员双声部

【AI推荐待确认｜创作；出处：CHI1293 W3–4 p08–10、p15 / W5–6 p04–06、p11】两种**关注**，不是两个道德阵营。职务与关注点是文案设定，模型可配置，不把任何品牌固定为“更仁”或“更真”。两者都可以认错，都需要证据。

| | 大副 · 求证 | 二副 · 义利提醒 |
| --- | --- | --- |
| 关注 | 这句话有没有依据，能证明到哪一步 | 这件事落在谁身上，谁没被看见 |
| 句式 | 陈述句为主，短，指向一份具体材料 | 问句为主，问“谁” |
| 名词 | 出处、记载、这一步、口径 | 谁、代价、后来的人、没开口的人 |
| 禁止 | 说“这是事实”而不给出处；替玩家下结论 | 训斥玩家；用悲情逼选；自称更有良心 |

| 情境 | 大副 | 二副 |
| --- | --- | --- |
| 开题 | 先挑一处能查证的细节。 | 这件事，会影响谁？ |
| 材料初见 | 这份记载能证明哪一步？ | 记录里，谁还没开口？ |
| 存疑 | 这句还缺出处，我先保留。 | 要是判断错了，谁来承担？ |
| 高效方案 | 步骤少了，哪部分还没查？ | 省下的时间，会不会落到别人身上？ |
| 分歧 | 我同意去查，暂不同意这个解释。 | 目标一样，这个代价我还想再问。 |
| 同一材料不同解 | 同一份材料，我们推得不一样。 | 可以先试，留着改的余地。 |
| 交还判断 | 依据在这里。采纳，或者再查。 | 我提醒到这里。理由和决定，由你留。 |
| 承认出错 | 我刚才引错了，更正在下面。 | 我之前没想到这一层，补上。 |

两人同屏时**并排**，各自的话保留各自的语气；不要把两句合成一段“船员们认为……”。

## 四、印章文字

【AI推荐待确认｜创作；出处：CHI1293 W3–4 p10、p15 / 作业2 p01–03】印面字尽量短；悬停或长按时显示一句解释。

| 印面 | 悬停解释 | 边界 |
| --- | --- | --- |
| 史实 | 有可核对的材料，请连同出处读。 | 仅核实后用；无出处不得盖 |
| 推演 | 依据材料推想，结果取决于条件。 | 写明假设 |
| 创作 | 为这段体验创作，不作历史依据。 | 虚构台词、人物、情境、概念图 |
| AI 推荐，待组员确认 | AI 的建议，组员还没确认。 | 可叠加在内容印旁 |
| 待核实 | 这条说法还在核对，先别当定论。 | 不得与“史实”同时出现 |
| 测试 | 测试数据，不代表任何文明或真实费用。 | 带斜纹 |
| 分歧 | 船员意见不同，各自理由都在。 | 纸色双线，不用朱砂 |
| 采纳 · 疑点 n | 你采纳了这个解释，疑点仍留着。 | 不是史实认证，不是组员审定 |

## 六、禁止与替代

【AI推荐待确认｜推演；出处：CHI1293 W1–2 / W3–4 / W5–6；产品编辑约束，承接 COPY_SEEDS「禁用与替代方向」】

| 禁止 | 典型坏句 | 为什么 | 改为 |
| --- | --- | --- | --- |
| **修仙** | “修为突破”“悟道成功”“境界提升” | 把修身写成超能力升级 | 看清问题、写下理由、承担选择 |
| **国潮贴纸** | 满屏篆书、“匠心”“东方美学”标签、给按钮加回纹 | 用纹样和古字代替文化动作 | 一份可核对的材料，一次可回看的决定 |
| **空洞五千年** | “穿越五千年文明”“千年智慧尽在掌握” | 给年代长度自动附加价值 | 写可核实的具体时段与地点 |
| **把技术当文明** | “最强模型带你进入最高文明”“智能即文明”“AI 已替你判断正确” | 技术变形式，判断仍在人 | 船员能帮你查什么；仍要你决定什么 |
| **道德计分** | “仁义值 +10”“文明等级领先”“诚信满分” | 把德性做成可刷数值 | 理由已记录 / 仍有疑点 / 可回看修订 |
| **孔乙己式戏谑** | 把求知者写成迂腐笑料 | 角色面对的是具体疑问 | 让角色问一个具体问题 |
| **名言滚屏** | 加载页轮播经典名句、政治讲话段落 | 口号占据下一步 | 名句若必要，留在出处页并核归属与语境 |
| **大字内核** | 按钮或横幅写“知行合一”“和而不同”“天下大同” | 内核只能被做到 | 见 ART_DIRECTION「只可被做到的概念」表 |
| **假完成** | “碎片已集齐，文明已重现” | 收集不是完成 | 已收入货舱，还没用上 |

## 七、写新句子前的四个检查

1. 不懂课程的人，读完知道**下一步按哪里**吗？
2. 这句话在**评价玩家的人格**吗？是就改成描述动作。
3. 这句话让**流畅听起来像真**吗？（“显然”“毫无疑问”“已证实”）有就删。
4. 这句话里的概念，能不能**换成一个动作或一盏灯**？能就别写成字。
