# 场景 A / B / C 视觉与文化候选

> **全部条目均为“AI 推荐，待组员确认”。** 不是已确认的正式文化设定，不是最终史实结论，也未经验证效果。可用于可替换的候选演示。
> 正式内容由场景负责人在 `scenes/A.md`、`scenes/B.md`、`scenes/C.md` 中确认填写；本文件不修改那三个模板。
> 下列出处为建议查阅的资料，具体页码、版本和授权需由组员核实后再引用。

三个候选刻意覆盖“古风 / 现代 / 未来”三种视觉，用来检验通用驾驶舱能否承载不同场景皮肤（见 [tokens.css](tokens.css) 中 `[data-scene]`）。

同一内核（知行合一，辅以和而不同、仁义）在三处的处境不同：A 问**互鉴是否真的发生**，B 问**标准的收益与代价落在谁身上**，C 问**今天的安排是否给后来者留了改写的余地**。三者共用 [ART_DIRECTION § 文明内核如何被看见](ART_DIRECTION.md#文明内核如何被看见) 的光、印与远灯语言，只换场景皮肤。

## A 候选：宋元泉州港——“世界的商港”（古风）

**标记**：AI 推荐，待组员确认 · 史实为主，可附反事实推演

| 项 | 内容 |
| --- | --- |
| 文明背景 | 10–14 世纪，泉州（刺桐）是东亚与印度洋贸易网络的重要港口，多种族群与宗教在此共处。 |
| 文化核心 | “和而不同”：商贸制度、多元信仰与地方社会如何共存。 |
| 探索问题 | 一座港口如何让不同语言、信仰和商业习惯的人长期合作？这种共处靠什么维系，又在什么条件下瓦解？ |
| 文化碎片方向 | 市舶管理制度；多语种宗教石刻；海船结构与水密隔舱；外销瓷与香料货单；地方民间信仰。 |
| 可交互机制 | 在港口登记货物（理解市舶制度）；比对不同来源对同一港口的记述；按水密隔舱原理修补船体的小任务。 |
| 经济互动 | 剧情货物：瓷器、丝织品、香料（测试数值）；港口抽税与航线风险的取舍。 |
| 教育意义 | 理解古代全球贸易与多元文化共存；练习比较不同来源（官方文书、旅行记、考古实物）。 |
| 视觉方向 | 黄昏港湾，暖褐与瓷白，船木与石材；建筑只做体块与剪影，不复原具体建筑外观。 |
| 实现成本 | 中。需要港口体块、古船外观皮肤、货物图标；石刻与文物图片需授权。 |

**建议资料**

- UNESCO 世界遗产名录：Quanzhou: Emporium of the World in Song-Yuan China（编号 1561，2021 年列入）及其申遗文本。
- 赵汝适《诸蕃志》（南宋）。
- 泉州湾宋代海船（1974 年后渚港发掘）相关考古报告；泉州海外交通史博物馆公开资料。
- 《马可·波罗行纪》、伊本·白图泰游记中关于“刺桐”的记述（作为旅行记，需与其他来源对照）。

**待核实问题**

1. “刺桐”与泉州的对应及马可·波罗是否亲至，学界有不同观点，需列出而非下结论。
2. 宋元市舶司的具体税率与流程，不同时期差异如何？
3. 宗教石刻图片的拍摄与使用授权（博物馆 / 公开数据库）。
4. 海船复原图的版本与来源。

### A · 文化透镜与视觉韵味：互鉴不是靠岸

> 【AI推荐待确认｜推演/创作；出处：CHI1293 W4–5 p06、p10 / W5–6 p11–12 / 作业2 p02；透镜依据：`docs/culture/SCENE_LENSES.md`（分支 docs/cultural-kernel）】仍是 AI 推荐，待组员确认。泉州“多信仰并处”为**史实候选·待核实**，不能扩成“从无冲突”。

**一句话**：货物靠岸以后，只有接收者选择、改造并延续所学，差异共处才可能成为互鉴。

| 层 | 做法 | 不要 |
| --- | --- | --- |
| 光 | 黄昏转夜：天边 `--cv-scene-sky-horizon` 的暖褐尚未退尽，码头灯陆续亮起。港口里**不同群体的灯保持不同形状**（圆灯、方灯、长灯）沿码头并排，亮度相同；不用任何具体宗教或族群纹样，只用几何形区分“不同” | 把所有灯统一成一种“古风灯笼”；用真实宗教符号做装饰 |
| 海图 | 两条线从远方汇入泉州：**货物流**为实铜线，一路到港；**知识流**为虚墨线，在缺证处断开，断点写“这里还没有证据”。玩家找到接收方主动选择、改造、延续三项证据时，虚线逐段描实；缺一项就停在那里 | 一靠港两线同时变实；“互鉴值”进度条 |
| 碎片 | 货单、往来记录、石刻遗存三类纸签；每张纸签同时显示“它能证明什么 / 不能证明什么”两行 | 把建筑数量当互鉴证据 |
| 行出来 | 一份**港口合作安排草案**：共同规则、容许保留的差异、尚未听见的声音三栏同宽；落印后，涉及的码头灯被描入日志 | 题作“宋元港规复原” |
| 远灯 | 港口之后 4–7L 的雾里有几盏无名小灯，代表文字记录里没开口的人（译者、船工、中介）；材料提到时被标出名字 | 把中介只画成抽成的障碍 |
| 船 | 通用宝船只作气势。场景标签旁固定小字“概念宝船，非本港当年船只”——宋元泉州不出现明代宝船的复原主张 | 让船的逼真为港口史实背书 |

**韵味关键词**：瓷白与船木、灯形各异而光一样暖、两条线一实一虚。

## B 候选：集装箱改变港口（现代）

**标记**：AI 推荐，待组员确认 · 史实为主，可附反事实推演

| 项 | 内容 |
| --- | --- |
| 文明背景 | 20 世纪中叶起，标准化集装箱让装卸、港口布局和全球分工发生大规模变化。 |
| 文化核心 | 标准如何塑造文明：一个看似简单的“盒子”改变城市、劳动和日常商品。 |
| 探索问题 | 标准化带来的效率由谁获益、谁承担代价？港口城市和码头工人的生活如何改变？ |
| 文化碎片方向 | 首批集装箱航运的记录；尺寸标准的形成；码头工人口述史；港口城市空间变化对照；价格与运输时间数据。 |
| 可交互机制 | 对比“散货装卸”与“集装箱装卸”两种港口的时间与人力（测试数值）；选择是否推行统一标准并承担后果。 |
| 经济互动 | 剧情资源：泊位、吊机、工人、运价；标准化后成本下降与就业变化的权衡。 |
| 教育意义 | 理解基础设施与制度标准对全球化的影响；讨论技术变革中的分配问题。 |
| 视觉方向 | 偏冷日光与钠灯，混凝土灰、钢蓝，安全橙点缀；集装箱用纯几何体，不出现真实航运公司标志。 |
| 实现成本 | 低。几何体为主，程序化堆场即可；口述史与历史照片需授权。 |

**建议资料**

- Marc Levinson, *The Box: How the Shipping Container Made the World Smaller and the World Economy Bigger*（Princeton University Press，2006 初版）。
- ISO 668 系列集装箱尺寸标准（标准文本需购买，仅引用其公开摘要）。
- 各港口管理机构公开的历史统计与档案。

**待核实问题**

1. 首次集装箱航运的具体日期、船名与航线说法需与原始档案对照。
2. 不同国家港口的转型时间差异较大，演示应选哪个港口为例？
3. 工人口述材料的授权与隐私处理。
4. 运价与效率数据的年份口径。

### B · 文化透镜与视觉韵味：标准是当代的“礼”，要接受“义”的追问

> 【AI推荐待确认｜推演/创作；出处：CHI1293 W1–2（礼）/ W5–6 p03–06（义利、隐去的劳动）/ W4–5 p06、p10；透镜依据：`docs/culture/SCENE_LENSES.md`】仍是 AI 推荐，待组员确认。“标准像礼”是文化类比，**不宣称现代标准是古礼的历史延续**。

**一句话**：标准像礼一样使协作可预期，但效率的收益和转型的代价分别落在谁身上，需要追问。

| 层 | 做法 | 不要 |
| --- | --- | --- |
| 光 | 堆场的钠灯与冷日光，网格整齐。**先真诚地给“标准”美感**：箱垛的几何秩序干净、可预期，这是礼的好处。随后在堆场边缘，旧码头的暖色小灯还亮着，位于 2–3L，不比钠灯暗太多 | 把集装箱画成冷酷反派；把旧码头画成怀旧滤镜 |
| 海图 | 同一份标准在海图上展开为整齐的格线；格线之下用铅笔点标出**没被计入“效率”的东西**（工作方式、城市空间、谁失去了机会），材料打开时铅笔点描成墨 | 装箱速度越快分越高的竞速 |
| 双声部 | 大副问档案与比较口径，二副问工人和被排除者；两人席位并排，任务卡上“采用理由”与“转型负担”两栏同宽 | 拉锯条、赞成/反对票数 |
| 行出来 | 一项**标准采用安排**的说明：保留何种地方做法、照顾何种转型负担、哪些异议未解决。落印后海图出现“谁受益 / 谁承担”两支同粗墨线 | 默认“统一标准天然是自愿合作” |
| 远灯 | 远处一排住宅窗灯（4–7L），代表港口城市里不在码头上的人；材料提到时被标出名字 | 把劳动者只画成受害者剪影 |

**韵味关键词**：钢蓝与混凝土、一抹安全橙、整齐之美与边缘的暖灯并存。

## C 候选：海平面上升后的漂浮港（未来）

**标记**：AI 推荐，待组员确认 · **未来创作**，以科学评估为依据，不是预测

| 项 | 内容 |
| --- | --- |
| 文明背景 | 以当代气候科学对海平面上升的评估为起点，创作一座未来的漂浮港口社区。 |
| 文化核心 | 迁徙与延续：当土地改变，文化如何被携带、改写和传承。 |
| 探索问题 | 一个社区在迁往海上时，应该保留什么、放弃什么、由谁决定？ |
| 文化碎片方向 | 气候评估报告中的情景与不确定性说明；现有漂浮建筑与适应性规划案例；虚构居民的日志（明确标“创作”）。 |
| 可交互机制 | 规划漂浮社区的模块（居住、种植、记忆馆）；在有限资源下决定携带哪些文化物件；不同船员给出相互冲突的方案。 |
| 经济互动 | 剧情资源：浮力模块、能源、淡水；资源分配影响社区成员的满意度（测试数值）。 |
| 教育意义 | 理解科学情景与不确定性；练习区分科学依据、推演与创作；讨论气候适应中的公平。 |
| 视觉方向 | 冷青与夜蓝，模块化浮体，低饱和；避免霓虹赛博朋克堆砌，“未来”体现在结构与生活方式。 |
| 实现成本 | 中。模块化体块可程序生成；不依赖真实遗址素材，授权风险最低。 |

**建议资料**

- IPCC 第六次评估报告第一工作组（AR6 WGI，2021）第 9 章及决策者摘要中关于海平面的部分。
- IPCC《气候变化中的海洋和冰冻圈特别报告》（SROCC，2019）。
- UN-Habitat 关于漂浮城市原型的公开资料（2022 年前后公布，进展需核实）。

**待核实问题**

1. 引用哪一组情景和年份的数据，如何在界面中表达不确定性范围？
2. 漂浮城市原型的当前状态（是否仍在推进）。
3. 若以某个真实地区为灵感，需避免把真实社区写成虚构故事的主角，并考虑当事人视角。

### C · 文化透镜与视觉韵味：给未出生者留一圈位置

> 【AI推荐待确认｜创作；概念出处：CHI1293 W1–2（生生）/ W3–4 p13–15（默会知识）/ W5–6 p11、p13（宇宙的时间责任）；透镜依据：`docs/culture/SCENE_LENSES.md`】仍是 AI 推荐，待组员确认。漂浮港是**创作，不是对任何地方的预测**；W12 生态专题仍为大纲待讲，不冒称已讲。

**一句话**：迁徙带走的不只是物件，还要给后人继续生活和改写文化的条件。

| 层 | 做法 | 不要 |
| --- | --- | --- |
| 结构 | 浮体模块按同心环系泊，这是“涟漪”唯一允许的字面形状，而且是**结构而非动画**：内环有人居住、灯亮；中环是公共与记忆模块；**最外一环是只有框架的空模块**，没有灯——这是留给后来者的位置 | 扩圈光波动画；把空环画成“待解锁” |
| 光 | 冷青与夜蓝，低饱和。内环窗灯是暖色，与船上的灯同一色温——未来的人点的还是同一种灯 | 霓虹、全息、赛博朋克堆砌 |
| 携带 | 携带的不只是物件：每件携带项旁有“谁还会做 / 谁愿意教 / 后人能否改写”三问；只回答了“带了什么”的条目保持铅笔色 | 限重行李式的文化价值排行；“保存得一模一样”为唯一好结局 |
| 行出来 | 一份**带修订入口的文化携带方案**；落印后外环空框架不被填满，而是在日志中显示“后来的人，还能改这份安排吗？” | 落印后外环亮起表示“未来已安顿” |
| 后来者 | 海平线方向（≥ 8.5L）无灯；日志最后一问指向那里 | 用虚构“未来居民”的悲情证言逼玩家选择 |
| 标识 | 场景标签常驻“创作 · 非预测”；引用的科学评估材料单独盖“推演”并写明情景与年份 | 把情景值写成确定的未来海平面 |

**韵味关键词**：冷海、暖窗、空着的那一圈。
