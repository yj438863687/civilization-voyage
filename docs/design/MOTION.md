# 动效规范

变量：`--cv-dur-*`、`--cv-ease-*`（见 [tokens.css](tokens.css)）。3D 侧的时长使用同样的数值，前端可从 CSS 变量读取或在常量文件中保持一致。

## 原则

1. 动效先服务反馈：用户做了什么、系统在做什么、结果是什么。
2. 装饰动画可关、可减，不影响任何信息获取。
3. 一屏同时只有一个“吸引注意”的动效（通常是等待用户选择的焦点）。
4. 不用动效掩盖等待：正在执行时显示步骤和事件，不用无限循环的炫光代替进度。

## 分类

### A. 必要反馈（减少动态模式下保留，改为淡入或直切）

| 场景 | 动效 | 时长 / 缓动 | 减少动态时 |
| --- | --- | --- | --- |
| 按钮按下 | 下沉 1px + 亮度变化 | instant / ease-out | 只变亮度 |
| 焦点 | 2px 外框出现 | fast | 同 |
| 面板进出 | 从右（手机从下）滑入 16px + 淡入 | base / ease-out | 只淡入 |
| 正在执行 | 进度条推进；事件逐条出现 | 每条 fast | 无位移，直接出现 |
| 等待用户选择 | 等待区铜色边线一次脉冲后常亮 | slow，仅 1 次 | 直接常亮 |
| 失败 | 失败卡出现 + 朱砂左边线 | base | 只淡入 |
| 资源变化 | 数字滚动到新值，旁边短暂显示 +n / −n | slow | 直接显示新值与 +n / −n |
| 落印（确认航程、成果生成） | 印章从 1.15 缩至 1 + 不透明度 0→1 | base / ease-out | 直接出现 |
| HUD 新事件 | 对应 HUD 块恢复不透明 | fast | 同 |

### B. 镜头（数值表）

坐标约定：船体局部坐标系，**+X 为船头方向，+Y 向上**。方位角 `az` 以船头为 0°，正值偏向船尾右侧；俯角 `el` 为机位高于目标的角度；距离以船长 `L` 为单位。`fov` 为**垂直**视场角（度）。目标点是船体中线居中、高度 `0.35L` 附近（约艉楼二层窗）或本表中另注的锚点。

| mode | fov | az | el | 距离 | 目标点 | blend 秒 | 曲线 | 可跳过 | 减少动态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `boot` 启航 | 38 | −25 | 10 | 1.80 L | 船中，y=0.35L | — | 静止 | — | 静止 |
| `boot.push` 启航→驾驶舱 | 42 | −25 → 舱内 | 10 → 0 | 1.80 L → 舱内 | 座位 → 海图桌 | 1.20 | smootherstep | 是 | 0.16s 交叉淡入 |
| `cockpit` 驾驶舱 | 55 | 舱内固定，朝向海图桌 | — | — | 海图桌中心 | — | — | — | — |
| `chart` 航线 | 45 | 0 | 65 | 2.40 L | 海图桌中心 | 1.00 | smootherstep | 是 | 0.16s 交叉淡入 |
| `sail` 航行 | 50 | 35 | 18 | 1.35 L | 船中 + 前方 0.60 L 前视偏移 | 1.80 | smootherstep | 是 | 0.16s 交叉淡入 |
| `approach` 靠港 | 42 | 60 | 12 | 0.90 L | 港口锚点 | 1.20 | smootherstep | 是 | 0.16s 交叉淡入 |
| `log` 反思 | 50 | 舱内固定，朝向日志 | — | — | 日志纸面 | 0.48 | ease-out | 否 | 0.16s 交叉淡入 |

曲线：

- `smootherstep`：`s = 6t⁵ − 15t⁴ + 10t³`，`t = elapsed / blendSec`。用于所有 1.0s 以上的镜头位移，起止速度为 0，无顿挫。
- 短过渡（`log`）用 `ease-out`：`s = 1 − (1−t)³`。
- 过渡期间 `t` 线性走完，插值对象为 `position`、`lookAt`、`fov` 三者各自独立缓动；`fov` 用同一 `s`，不额外偏移。

规则：

- 单个镜头过渡不超过 1.8s；点击/轻触即跳到终点（`blendSec = 0`，直接置 `s = 1`）。
- 过渡期间输入锁定，HUD 保持可见但 60% 不透明，结束后恢复。
- 不做镜头抖动、手持晃动与快速旋转。
- 航行机位不做自由轨道：方位与俯角固定，只跟随船位与航向。

### B2. 跟船弹簧

用指数阻尼（不是冲量弹簧，避免过冲与晕动）：

```
damp(current, target, dt, tau) = target + (current − target) * exp(−dt / tau)
```

| 通道 | tau | 说明 |
| --- | --- | --- |
| 机位横向（相对船的左右偏移） | 0.18 s | 转向时镜头略滞后于船，产生“甩”的余地 |
| 机位前后距离 | 0.30 s | 加减速时轻微伸缩 |
| 机位垂直（随波起伏） | 0.45 s | 镜头起伏幅度取船体起伏的 35%，避免与船同步晃动 |
| 朝向 yaw | 0.35 s | 转向时船头先动，镜头随后 |
| 朝向 pitch | 0.50 s | 只跟随缓慢趋势，跟着浪走会晕 |

- 转向速率超过 12°/s 时，额外把镜头向外侧偏移最多 `0.12L`，权重 `min(turnRate/60, 1)`，偏移本身用 tau 0.6 s 阻尼。
- 减少动态：所有 tau 置 0（刚性跟随），垂直通道直接锁定为 0 起伏。

### B3. HUD 与过场

| 项 | 值 |
| --- | --- |
| 启航页 letterbox | 视口宽高比 ≥ 1.9 时上下各加黑边，比例 `2.39:1`；进入驾驶舱后 1.2s 内收起 |
| letterbox 颜色 | `--cv-cine-bar`，纯色不透明 |
| HUD 进入 | 航行开始时左上、右上、右下依序淡入，间隔 80ms，总 320ms |
| HUD 隐去 | 3s 无操作且无待办 → 0.85 透明降至 0.6，`fast` |
| 靠港提示 | 进入港口半径 `1.2L` 时中央提示出现，`base` 淡入 + 上移 8px |
| 罗盘刻度 | 随航向旋转，yaw 变化直接映射，无额外缓动（读数必须即时真实） |


### C. 船与世界（装饰，可关闭）

所有角度单位为度，周期单位为秒，时间用累计 `t`（秒）。可直接写进 `useFrame` 或顶点着色器里，振幅与周期命名见 [交接清单](../handoffs/claude-to-grok.md) §2.3。

#### C1. 船体起伏（船模型局部旋转，绕重心轴，不是绕原点）

```
pitch = A_pitch * sin(2π t / T_pitch + φ_pitch)
roll  = A_roll  * sin(2π t / T_roll  + φ_roll) + heel
yaw   = A_yaw   * sin(2π t / T_yaw   + φ_yaw)
heave = A_heave * sin(2π t / T_heave + φ_heave)
```

| 通道 | 静止 / 低速 | 巡航 | 周期 | 相位（默认） |
| --- | --- | --- | --- | --- |
| 纵摇 pitch | ±0.8° | ±1.4° | 5.0 s | 0 |
| 横摇 roll | ±1.2° | ±2.2° | 6.5 s | π/3 |
| 艏摇 yaw | ±0.4° | ±0.7° | 8.0 s | π |
| 垂荡 heave | ±0.012 L | ±0.020 L | 4.5 s | π/2 |

- 振幅随相对风速缩放：`k = clamp(0.6 + 0.4 * windFactor, 0.6, 1.4)`，`windFactor` 为当前场景风力 0–1，缺省 0.5。
- 周期随船速略缩：`T' = T / (1 + 0.15 * speedFactor)`，`speedFactor` 0–1，缺省 0。
- 俯仰与横摇用小幅相位差，避免“整块板在晃”的感觉；垂荡与纵摇反相（船头入水时整体下沉）。

#### C2. 转向横倾 heel

```
heelTarget = -clamp(turnRate / 15, -1, 1) * 4.0°     // 右转右倾，最大 4°
heel       = damp(heel, heelTarget, dt, 0.9)          // 指数阻尼，tau 0.9s
```

- 上限 4°，永不叠加到超过 6° 总横摇。
- 静止时 `turnRate = 0`，横倾回正，tau 1.6s（比倾斜慢，回正更柔）。

#### C3. 尾迹

| 项 | 值 |
| --- | --- |
| 形状 | 船尾开始的 V 形两条尾流 + 船侧两道光带，用贴图沿 UV 滚动，不做粒子 |
| 宽度 | 船艉宽度 1.0 倍起，随距离线性扩至 1.8 倍（在 6L 处） |
| 长度 | `3.0L + 4.0L × speedFactor`，最长 7L 处淡出至 0 |
| 流动速度 | UV 沿船尾方向滚动 `0.35 / s × (0.4 + speedFactor)` |
| 不透明度 | `0.42 × speedFactor`，静止时 = 0（不显示静止尾迹） |
| 颜色 | 场景水色的 1.35 倍亮度，不做纯白 |
| 泡沫碎点 | 只在艉部 1.2L 内，噪声阈值 0.72，随速度增强 |

#### C4. 帆面鼓风

- 帆面按行（横杆之间）分段，每段一块平面 + 一条折线，鼓风是**逐段位移**而非整面弯曲。
- 鼓出量：`bulge = 0.035L * windFactor * sin(2π t / 4.2 + rowIndex * 0.6)`，主帆 0.035L，前桅 0.028L。
- 折线位置固定在每段中线，随 bulge 平移，折线的明暗对比用 `--cv-ship-sail` / `--cv-ship-sail-shade`，不做布纹动画。
- 帆的轻微抖动：额外 `0.004L * sin(2π t / 0.9 + rowIndex)`，仅在前 2 段。
- 收帆：段数减少时，段高度用 `base` 缓动到 0.15 倍并向下平移，不整体缩放。

#### C5. 其他

| 对象 | 参数 | 减少动态时 |
| --- | --- | --- |
| 海面法线流动 | UV 速度 `0.03 / s`，法线强度 0.6 | 静止 |
| 水线雾 | 沿水线一圈的软雾带，高度 `0.05L`，密度随场景 `--cv-scene-fog` | 保留静态雾，不流动 |
| 启航页微动 | 只让海面流动与帆轻微起伏，机位固定，无环绕 | 静止 |
| 舱内灯光 | 恒定，不做闪烁 | 同 |
| 灯笼/舷灯 emissive | 恒定，不做呼吸；只有“正在执行”时舷灯亮度 +8%，`slow` 一次 | 恒定 |
| 碎片标记 | 上下浮动 2px，周期 3s | 静止 |
| 文明重现三阶段 | 线框 → 体块 → 材质，各阶段 `slow` 过渡，与进度绑定 | 直接切换 |


## 减少动态

- 读取 `prefers-reduced-motion: reduce`，同时在设置中提供“减少动态效果”开关，开关优先于系统设置。
- 开启后：tokens.css 中的时长变量自动缩短；3D 侧关闭 C 类全部动效，B 类改直切；渲染可降为按需渲染（场景无变化时不重绘）。
- 不因减少动态而隐藏任何信息或状态。

## 性能

- 动画只改 `transform` 与 `opacity`。
- 低端设备（帧率持续低于 30）自动关闭 C 类中的海面流动与尾迹，并在设置中显示已降级。
