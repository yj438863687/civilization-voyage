# 动效规范

变量：`--cv-dur-*`、`--cv-ease-*`（见 [tokens.css](tokens.css)）。3D 侧的时长使用同样的数值，前端可从 CSS 变量读取或在常量文件中保持一致。

## 原则

1. 动效先服务反馈：用户做了什么、系统在做什么、结果是什么。
2. 装饰动画可关、可减，不影响任何信息获取。
3. 一屏同时只有一个“吸引注意”的动效（通常是等待用户选择的焦点）。
4. 不用动效掩盖等待：正在执行时显示步骤和事件，不用无限循环的炫光代替进度。

## 分类

### A. 必要反馈（减少动态模式下保留，改为淡入或直切）

| 场景 | 动效 | 时长 / 缓动 | 减少动态时 |
| --- | --- | --- | --- |
| 按钮按下 | 下沉 1px + 亮度变化 | instant / ease-out | 只变亮度 |
| 焦点 | 2px 外框出现 | fast | 同 |
| 面板进出 | 从右（手机从下）滑入 16px + 淡入 | base / ease-out | 只淡入 |
| 正在执行 | 进度条推进；事件逐条出现 | 每条 fast | 无位移，直接出现 |
| 等待用户选择 | 等待区铜色边线一次脉冲后常亮 | slow，仅 1 次 | 直接常亮 |
| 失败 | 失败卡出现 + 朱砂左边线 | base | 只淡入 |
| 资源变化 | 数字滚动到新值，旁边短暂显示 +n / −n | slow | 直接显示新值与 +n / −n |
| 落印（确认航程、成果生成） | 印章从 1.15 缩至 1 + 不透明度 0→1 | base / ease-out | 直接出现 |
| HUD 新事件 | 对应 HUD 块恢复不透明 | fast | 同 |

### B. 镜头（减少动态模式下改为直切 + 0.16s 淡入淡出）

| 过渡 | 运动 | 时长 |
| --- | --- | --- |
| 启航页 → 驾驶舱 | 船外 → 穿过舱门 → 舱内，推进 | camera（1.2s），ease-swell |
| 驾驶舱 → 航线 | 舱内平视 → 俯视海图桌 | camera |
| 航线 → 航行 | 海图桌 → 拉出舱外 → 第三人称跟船 | camera × 1.5 |
| 接近港口 → 场景 | 跟船 → 推近港口，场景色从 0 渐入 | camera |
| 场景 → 反思 | 淡出到舱内日志 | slow |

规则：
- 镜头运动期间界面输入暂停，不超过 1.8s；用户点击可跳过。
- 不做镜头抖动、晃动与快速旋转。
- 航行中跟船镜头有弹簧阻尼，转向时延迟约 0.3s 跟随，避免晕动。

### C. 船与世界（装饰，可关闭）

| 对象 | 动效 | 参数建议 | 减少动态时 |
| --- | --- | --- | --- |
| 船体起伏 | 纵摇 ±1.5°、横摇 ±2°，周期 4–6s | ease-swell | 关闭 |
| 尾迹 | 速度相关的白色尾迹 | — | 保留静态尾迹 |
| 海面 | 法线贴图流动 | 慢速 | 静止 |
| 启航页环绕镜头 | 绕船 1 圈 / 60s | 线性 | 静止 |
| 舱内灯光 | 不做闪烁 | — | — |
| 碎片标记 | 轻微上下浮动 2px，周期 3s | — | 静止 |
| 文明重现三阶段 | 线框 → 体块 → 材质，各阶段间 slow 过渡 | 与进度绑定 | 直接切换阶段 |

## 减少动态

- 读取 `prefers-reduced-motion: reduce`，同时在设置中提供“减少动态效果”开关，开关优先于系统设置。
- 开启后：tokens.css 中的时长变量自动缩短；3D 侧关闭 C 类全部动效，B 类改直切；渲染可降为按需渲染（场景无变化时不重绘）。
- 不因减少动态而隐藏任何信息或状态。

## 性能

- 动画只改 `transform` 与 `opacity`。
- 低端设备（帧率持续低于 30）自动关闭 C 类中的海面流动与尾迹，并在设置中显示已降级。
