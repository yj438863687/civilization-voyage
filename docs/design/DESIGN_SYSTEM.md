# 设计系统

变量源文件：[tokens.css](tokens.css)。前端只引用语义变量（`--cv-surface-*`、`--cv-text-*`、`--cv-state-*`、`--cv-mark-*`、`--cv-ledger-*`），不直接写色值。

## 1. 颜色

### 基础色阶

| 组 | 变量 | 用途 |
| --- | --- | --- |
| 墨海 | `--cv-ink-950 … 500` | 背景、舱壁、面板 |
| 纸 | `--cv-paper-50 … 300`、`--cv-paper-ink` | 海图、日志、材料卡，纸上用墨字 |
| 铜 | `--cv-brass-300 … 600` | 仪器、次要按钮、等待选择 |
| 海 | `--cv-sea-300 … 500` | 运行中、史实标记、真实用量 |
| 朱砂 | `--cv-cinnabar-400 … 600` | 用户主操作、失败 |
| 玉 | `--cv-jade-300 … 500` | 完成、成果 |
| 琥珀 | `--cv-amber-400` | 资源不足、AI 推荐待确认 |
| 石板 | `--cv-slate-300 … 600` | 未接入、禁用、测试 |

### 对比度要求

- 正文对比度不低于 4.5:1，HUD 小字不低于 4.5:1，大标题不低于 3:1。
- 深色面上的文字用 `--cv-text`（约 16:1）或 `--cv-text-muted`（约 8:1）；`--cv-text-faint` 只用于不承载信息的辅助刻度。
- 朱砂作为文字时用 `--cv-cinnabar-400`（深底约 5.4:1）；`--cv-cinnabar-500` 只作底色，上面放纸色字。
- HUD 叠在 3D 画面上时必须有 `--cv-hud-scrim` 底板，不能直接把字放在海面上。

## 2. 字体

| 角色 | 变量 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| 首屏标题 | display | `--cv-text-3xl` 52 | tight | 只在启航页 |
| 章节 | display | `--cv-text-2xl` 36 | tight | 航程名、成果标题 |
| 页面标题 | display | `--cv-text-xl` 26 | tight | 各页标题 |
| 面板标题 | display | `--cv-text-lg` 20 | tight | 面板、海图卡 |
| 正文 | body | `--cv-text-md` 16 | 1.7 | 对话、材料、日志 |
| 次要 / HUD | body | `--cv-text-sm` 14 | 1.5 | 说明、HUD |
| 标签 | body | `--cv-text-xs` 12，字距 0.08em | 1.4 | 印章、刻度、字段名 |
| 数字 | mono | 随所在层级 | — | 用量、预算、坐标、时间，`font-variant-numeric: tabular-nums` |

手机端整体不缩小正文，最小 14px；标题在 `<640px` 降一级。

字体加载：Google Fonts 加载 Noto Serif SC（500/600）、Noto Sans SC（400/500/600）、IBM Plex Mono（400/500）。中文字体体积大，前端可按需子集化，失败时退到系统字体，不阻塞首屏。

## 3. 间距与网格

- 4px 基准，变量 `--cv-space-1 … 16`。
- 面板内边距：桌面 `--cv-space-6`，手机 `--cv-space-4`。
- 组件间距：同组 `--cv-space-2/3`，不同组 `--cv-space-6`，区块之间 `--cv-space-10`。
- 断点：`sm < 640`，`md 640–1023`，`lg 1024–1439`，`xl ≥ 1440`。
- HUD 离视口边缘 `--cv-hud-edge`（16px），手机加 `env(safe-area-inset-*)`。

## 4. 尺寸

| 项目 | 值 |
| --- | --- |
| 最小触控区 | 44 × 44（`--cv-touch-min`） |
| 控件高度 | 32 / 40 / 48（sm / md / lg），手机一律 ≥ 44 |
| 侧栏面板 | 360（`--cv-panel-side-w`） |
| 任务 / 材料面板 | 480（`--cv-panel-wide-w`） |
| 阅读宽度 | 68ch（`--cv-reading-max`） |
| 船员席位 | 64 圆形（`--cv-crew-seat`） |
| 圆角 | 2 / 4 / 8；圆形只给状态点与席位 |

## 5. 材质

| 材质 | 实现 | 用在 |
| --- | --- | --- |
| 舱壁面板 | `--cv-surface-1` 实色 + `--cv-line` 1px 边 + `--cv-shadow-panel` | 对话、船员、通讯台 |
| 纸 | `--cv-surface-paper` + `--cv-shadow-paper`，可加 2–3% 噪点纹理 | 航程任务卡、海图、日志、材料 |
| 铜件 | `--cv-border-brass`，文字 `--cv-brass-300` | 次要按钮、刻度、选择器 |
| 印章 | 2px 圆角矩形，1px 边，内填 12% 同色，文字 12px | 内容性质、状态标签 |
| HUD 底板 | `--cv-hud-scrim`，无模糊，4px 圆角 | 3D 之上的信息 |
| 测试斜纹 | `--cv-ledger-test-hatch` 叠在底色上 | 测试货币、测试海域数据 |

禁止：`backdrop-filter: blur`、外发光边框（焦点除外）、多层透明叠加卡片。

## 6. 组件要点

### 按钮

| 类型 | 外观 | 用法 |
| --- | --- | --- |
| 主（落印） | 朱砂底、纸色字 | 用户做决定：确认航程、启航、提交成果。一屏一个 |
| 次（铜） | 透明底、铜边、铜字 | 常规操作 |
| 幽灵 | 无边、muted 字 | 取消、返回 |
| 图标（HUD） | 40/44 方形，scrim 底 | 地图、日志、通讯台 |

状态：悬停提亮一级；按下 `--cv-dur-instant` 内位移 1px；焦点 2px `--cv-focus-ring` 外框，偏移 2px；禁用 40% 不透明并在旁边说明原因。

### 船员席位

圆形席位 + 职务名（大副、二副、领航员……）+ 模型标签（小号 mono，例如“模型：未配置”）。发言时席位边框变 `--cv-state-running` 并显示“正在回复”。模型未接入时席位为虚线边、“尚未接入”。

### 对话

- 船员发言放在舱壁面板上，左对齐，前置席位缩略头像和职务名。
- 用户发言右对齐，纸色底。
- 船员之间意见不同时，用“分歧”印章（`--cv-mark-dissent`）把两条发言并排或连线，不合并成一条结论。
- 船员引用材料时，发言下方附出处条（来源名、链接、性质印章）。
- 不展示模型隐藏推理，只展示可观察事件：开始回复、调用工具、工具结果、引用材料、完成。

### 航程任务卡（纸）

标题（文化问题）、目标、参与船员、保留的分歧、性质标记、状态。确认后加朱砂印“已定航”。

### 内容性质印章

| 印章 | 颜色变量 | 形状提示 |
| --- | --- | --- |
| 史实 | `--cv-mark-fact` | 实线边，必须附出处 |
| 推演 | `--cv-mark-counterfactual` | 实线边 + “推”字前缀 |
| 创作 | `--cv-mark-creative` | 实线边 + “创”字前缀 |
| AI 推荐，待组员确认 | `--cv-mark-ai-pending` | 虚线边 |
| 测试数据 | `--cv-mark-test` | 斜纹底 |
| 分歧 | `--cv-mark-dissent` | 纸色双线边；不是错误，不用朱砂 |
| 待核实（编辑批注） | `--cv-mark-unverified` | 虚线边 + 右上问号角标；不得与“史实”同时出现 |
| 玩家采纳 | `--cv-mark-adopt` | 朱砂实印，印面“采纳 · 疑点 n”；与性质印并列，不替换它 |

颜色之外必须有文字，不能只靠颜色区分。

性质印（史实 / 推演 / 创作 / 测试）、审议印（AI 推荐待确认 / 待核实）、采纳印是三层，分开放置、不互相覆盖。场景状态“已确认”属于审议层，不得借用史实印样式。理由见 [ART_DIRECTION.md § 印章体系](ART_DIRECTION.md#印章体系既是控件也是信的视觉)。

**落印控件**：按住约 600ms 落印，中途松手取消；理由为空时印为空心描边且不可按。减少动态时以进度环代替下落动画，不取消按住。

### 两本账

| 账本 | 视觉 | 说明 |
| --- | --- | --- |
| 真实用量 | 海色等宽数字，前置“真实”标签，显示预算 / 已用 / 计量单位 | 未接入时整块为虚线边，显示“尚未接入”，不显示 0 或假数字 |
| 剧情资源 | 铜色图标 + 数量，前置“剧情”标签 | 货物、补给、声望等游戏内资源 |
| 测试资源 | 剧情样式 + 斜纹底 + “测试”印章 | 不得称为 HMT |

两本账在同一屏出现时上下分开，中间有分隔线和标题，不放在同一行。

## 7. 状态规范

每个状态 = 颜色 + 图标 + 文字 + 下一步操作。

| 状态 | 变量 | 图标建议 | 文案示例 | 下一步 |
| --- | --- | --- | --- | --- |
| 尚无航程 | `--cv-state-idle` | 空罗盘 | “还没有航程。和船员聊聊你想了解的文化问题。” | 新航程 |
| 正在执行 | `--cv-state-running` | 转动的舵轮（减少动态时静止 + 省略号） | “二副正在查阅材料（第 2 步 / 共 4 步）” | 查看过程、停止 |
| 等待用户选择 | `--cv-state-waiting` | 铜色手形 / 印章 | “船员给出两种解释，请选择或补充。” | 选项按钮 |
| 模型服务尚未接入 | `--cv-state-unconnected` | 断开的通讯线，虚线边 | “模型服务尚未接入。到通讯台填写你自己的服务配置。” | 打开通讯台 |
| 任务失败 | `--cv-state-failed` | 断缆 | “查阅材料失败：<服务返回的错误摘要>” | 重试、换航线、返回 |
| 资源不足 | `--cv-state-insufficient` | 空货舱 | “补给不足：需要 3，当前 1（剧情资源）” / “真实预算已用尽” | 调整预算、换较简单航线 |
| 成果已生成 | `--cv-state-done` | 玉印 | “文明成果已生成，已写入航海日志。” | 查看成果、反思 |

失败和资源不足必须说明是哪本账、哪一步、原因原文（去除凭据后），不能显示为成功或静默重试。
