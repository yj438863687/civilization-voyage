# 页面规范

视觉方向见 [ART_DIRECTION.md](ART_DIRECTION.md)，变量见 [tokens.css](tokens.css)。本文的布局为目标结构，具体像素可由前端按运行效果调整（见 [交接说明](../handoffs/claude-to-grok.md)）。

## 全局结构

```
┌────────────────────────────────────────────┐
│ 3D 画布（始终在底层，z: world）             │
│  ┌ HUD 左上：航程名 / 当前任务 ┐ ┌ HUD 右上：资源（两本账）┐ │
│                                             │
│        世界标签（港口、碎片，随 3D）         │
│                                             │
│  └ HUD 左下：航向/速度 ┘   └ HUD 右下：操作 ┘ │
└────────────────────────────────────────────┘
面板从右侧（桌面）或底部（手机）滑入，覆盖 3D 但不切走 3D。
```

- 全应用只有一个 3D 画布，页面切换通过镜头和面板完成，不重新加载世界。
- 一级导航不是侧边栏菜单，而是四段航程的“航程条”：驾驶舱 → 航线 → 世界 → 反思。当前段高亮，后续段在前置条件未满足时显示锁定原因。
- “通讯台”（模型服务配置）是抽屉，入口在驾驶舱和航线页的 HUD 右下，不放在一级导航。

## 1. 初次进入与航程选择（启航）

**目的**：让用户在 5 秒内理解“我有一艘船，可以去不同文明”，并开始或继续航程。

**布局（桌面）**

- 3D：船停在夜港，镜头在船外斜后方缓慢环绕（减少动态时静止）。
- 左侧 1/3：标题“文明航程”（`--cv-text-3xl`），一句说明，主按钮“新航程”（朱砂），次按钮“继续航程”。
- 右侧：已有航程列表（纸卡片），每张显示航程名、场景、上次停留段、更新时间。
- 底部：场景 A/B/C 候选入口，每个带“AI 推荐，待组员确认”印章；测试海域单独一行，带“测试”印章。

**状态**

- 尚无航程：右侧列表替换为空状态（空罗盘 + “还没有航程”），只保留“新航程”。
- 模型服务尚未接入：不阻止进入。顶部一条石板色提示“模型服务尚未接入，船员暂时不能回复，仍可浏览海域与材料”，附“打开通讯台”。

**窄屏（< 640）**：标题与主按钮在上，3D 缩为上半屏背景，航程列表在下方纵向排列，场景入口改为横向滑动。

## 2. 文化驾驶舱与船员对话

**目的**：与船员讨论，形成“文化问题 + 共同航程任务”，保留分歧。

**布局（桌面 ≥ 1024）**

```
┌──────┬──────────────────────────┬───────────────┐
│船员席│      对话区（舱壁面板）    │ 航程任务卡（纸）│
│ 大副 │  船员发言 / 用户发言       │ 文化问题        │
│ 二副 │  分歧并排                  │ 目标            │
│ +席位│  出处条                    │ 保留的分歧      │
│      │ ───────────────────────── │ 性质标记        │
│      │  输入框  [发送]            │ [确认航程]朱砂  │
└──────┴──────────────────────────┴───────────────┘
3D 背景：舱内，舷窗外是候选海域，亮度降至约 40%
```

- 左栏 88px：船员席位纵列，底部“+ 添加船员”（角色与模型均可配置）。
- 中栏：对话，最大宽度 `--cv-reading-max`。
- 右栏 `--cv-panel-side-w`：航程任务卡，随对话更新，用户可直接编辑字段。
- 主操作：“确认航程”（朱砂），未形成文化问题时禁用并说明原因。

**视觉层级**：任务卡 > 最新发言 > 船员席位 > 历史发言。

**状态**

- 正在执行：发言船员席位亮海色边，对话底部显示可观察事件（“查阅材料：xxx”），可停止。
- 模型服务尚未接入：该船员席位虚线边，发言区显示一条未接入提示，不出现假回复。
- 任务失败：失败的那条回复位置显示失败卡（原因 + 重试），其余对话保留。

**窄屏**：船员席位改为顶部横排小头像；任务卡收为底部抽屉，抽屉把手显示“航程任务（草稿）”；输入框固定在底部。

## 3. 航线、预算与资源

**目的**：在“较简单、成本较低”和“步骤较多、成本较高”的探索方式之间做选择，并看清依据、预算和用量。

**布局（桌面）**

- 3D：镜头俯视海图桌，海图占画面中部。两条航线以墨线画在海图上，选中的航线加粗并沿线出现步骤节点。
- 右侧面板（`--cv-panel-wide-w`）：
  1. 航线对比：两列，每列包含步骤数、步骤名、参与船员 / 工具、预计真实用量（区间）、预计剧情资源消耗、适合的问题类型、局限。
  2. 选择依据：一段文字说明“为什么推荐这条”，并固定一句提示“步骤多、成本高不代表结论更正确”。
  3. 预算：真实用量上限输入（单位跟随用户所接服务），剧情资源分配。
  4. 两本账：真实（已用 / 预算）与剧情（当前持有），上下分开。
- 主操作：“按此航线启航”（朱砂）。

**状态**

- 模型服务尚未接入：真实用量区整块虚线边，显示“尚未接入”，预计用量显示“—”，启航按钮仍可用于不需要模型的离线探索（若后端支持），否则禁用并说明。
- 资源不足：超出预算的航线卡片显示琥珀色“预算不足”，给出差额和“换较简单航线”。
- 测试数据：所有虚构数值带“测试”印章与斜纹。

**窄屏**：海图缩为顶部 40% 高度；两条航线改为上下两张卡，可左右滑动对比；预算与账本在卡片下方。

## 4. 全屏 3D 航行与 HUD

**目的**：自由航行，同时随时看清任务和资源。

**HUD 布局**

| 位置 | 内容 | 尺寸 |
| --- | --- | --- |
| 左上 | 航程名、当前任务一行、进度（第 n / m 步） | 宽 ≤ 320 |
| 右上 | 两本账缩略：真实用量（或“尚未接入”）、剧情资源 3 项以内 | 宽 ≤ 280 |
| 正上 | 场景标签（`--cv-scene-label`），离开测试海域 / 候选场景时消失 | 单行 |
| 左下 | 罗盘航向、速度、离下一目的地距离 | 120 × 120 罗盘 |
| 右下 | 图标按钮：海图、航海日志、驾驶舱、通讯台 | 40/44 |
| 中央 | 无常驻元素；只在接近目标时出现提示 | — |

- HUD 每块都有 `--cv-hud-scrim` 底板。
- 用户 3 秒无操作且无待办时，左上与右上 HUD 降为 60% 不透明，有新事件时恢复。
- 操作：WASD / 方向键或点击海面目标点航行；手机为左下虚拟摇杆 + 点按目标。

**窄屏**：左上与右上合并为顶部一条（任务 + 资源缩略），罗盘缩到 88px，右下操作收为一个“更多”按钮展开。

## 5. 接近港口、进入场景、发现碎片

**流程**：进入港口范围 → 中央提示“接近 <港口名>（AI 推荐，待组员确认）” + 按钮“靠港” → 镜头推近 → 场景色接管 → 场景内可移动的视点 → 碎片以纸签标记出现在世界中。

**碎片标记**：小纸签 + 性质印章色点；距离近时展开为标题。点击打开“材料面板”（右侧纸面板）：

- 标题、性质印章（史实 / 推演 / 创作 / 测试）
- 内容摘录
- 出处：来源名、作者 / 机构、链接、授权说明
- “待核实”问题（如有）
- 操作：“收入货舱”（加入本航程材料）、“请船员解释”

**状态**

- 素材缺失：港口用体块与剪影，显示“素材待补”小签。
- 碎片未附出处：不允许标为史实，自动显示“出处待补”。

**窄屏**：材料面板改为全屏底部抽屉，3D 保留顶部 30%。

## 6. 与 Agents 协作完成任务

**目的**：用户与 Agents 一起解释、选择并重现文明，过程可观察。

**布局（桌面）**

- 3D：场景内，镜头固定在“工作视角”（可旋转查看）。正在重现的对象以线框 → 体块 → 完成材质三阶段呈现（与任务进度对应）。
- 右侧任务面板（纸，`--cv-panel-wide-w`）：
  1. 任务目标与当前步骤
  2. 执行事件流：时间、Agent 职务、事件类型（开始 / 调用工具 / 工具结果 / 引用材料 / 完成 / 失败），可展开看工具结果与出处
  3. 等待选择区：Agent 给出的不同解释并列，每个附依据与性质印章；用户选择、修改或补充
  4. 经济后果预览：本选择对剧情资源的影响（加 / 减），真实用量单独一行
- 主操作：“采纳此解释”/“提交重现”（朱砂）。

**状态**

- 正在执行：事件流顶部有进度条与“停止”。
- 等待用户选择：等待区加铜色左边线与 `--cv-shadow-lamp`，HUD 左上任务行同步显示“等待你的选择”。
- 任务失败：事件流中失败事件展开显示原因；面板顶部给出“重试本步 / 换航线 / 返回驾驶舱”。
- 资源不足：在等待区直接说明哪本账不足及差额。

**窄屏**：3D 占上半屏；任务面板占下半屏，分“步骤 / 事件 / 选择”三个标签页，等待选择时自动切到“选择”。

## 7. 文明成果、航海日志与反思

**目的**：回顾来源、选择、过程和作品，支持再次航行。

**布局（桌面）**

- 3D：回到舱内，镜头对准海图桌上的航海日志，亮度降低，日志为纸面主体（宽 `--cv-reading-max` 居中）。
- 日志结构（纵向）：
  1. 成果：标题、成果形式（文字 / 图 / 3D 场景快照），性质印章，“概念创作”与“史实材料”分区
  2. 航迹：缩略海图 + 停靠点
  3. 选择记录：每个关键选择的时间、选项、依据、后果
  4. 材料与出处：本航程收集的碎片列表
  5. 两本账结算：真实用量合计（或“尚未接入”）、剧情资源变化
  6. 反思：几个引导问题 + 用户书写区
- 右侧窄栏：目录锚点。底部操作：“带着这次航程再次出发”（朱砂）、“导出日志”。

**状态**

- 成果已生成：顶部玉色印“已生成”，进入时有一次落印动效。
- 成果未完成：显示已完成部分，未完成部分标“未完成”，不补假内容。

**窄屏**：单栏阅读，目录收为顶部下拉；操作固定底部。

---

## 通讯台（模型服务配置，抽屉）

- 入口：驾驶舱与航线页右下 HUD；未接入提示中的链接。
- 内容：已配置服务列表（名称、状态、角色分配），“添加服务”表单（字段由后端接口定义），船员 → 模型分配。
- 凭据输入框为密码类型，保存后只显示“已配置”与末尾掩码，不回显，不写入日志。
- 抽屉宽 `--cv-panel-side-w`，手机为全屏。

## 状态总表

| 状态 | 出现位置 | 主要表现 |
| --- | --- | --- |
| 尚无航程 | 启航、反思 | 空罗盘 + 引导 + 新航程 |
| 正在执行 | 驾驶舱、Agents 协作、HUD | 海色进度 + 可观察事件 + 停止 |
| 等待用户选择 | 驾驶舱、航线、Agents 协作、HUD | 铜色边 + 焦点灯光 + HUD 同步 |
| 模型服务尚未接入 | 全局 | 虚线边 + “尚未接入” + 通讯台入口，不出现假回复或假用量 |
| 任务失败 | 任意执行处 | 朱砂文字 + 原因 + 重试 / 换航线 / 返回 |
| 资源不足 | 航线、Agents 协作、HUD | 琥珀色 + 指明哪本账 + 差额 + 替代方案 |
| 成果已生成 | 反思、HUD 通知 | 玉印 + 进入日志 |
