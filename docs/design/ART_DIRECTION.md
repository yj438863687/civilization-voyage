# 审美方向：墨海铜灯

> 状态：视觉负责人提案，供小组讨论。设计变量见 [tokens.css](tokens.css)，组件规范见 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)。

## 一句话

夜里的一间海图室：舱外是深墨色的海，舱内一盏铜灯照着摊开的海图和日志。用户坐在海图桌前，和船员讨论去哪，在图上落印确定航线，然后推开舱门出海。

## 为什么选这个方向

| 需要 | 做法 |
| --- | --- |
| 有游戏空间感，不像管理后台 | 主界面是一个有纵深的 3D 船舱，面板是舱内的实物（海图、日志、通讯台），不是网页卡片 |
| 能装载古风、现代、未来不同场景 | 船舱和海图桌是“中性容器”，用墨、纸、铜这些跨时代材质；文明的视觉只出现在舷窗外和登陆后的场景里 |
| 让用户看清任务、资源与进展 | 夜色背景压低环境，信息放在纸面和铜刻度上，对比清楚；一屏只有一处被灯光照亮的焦点 |
| 区分史实、推演、创作和测试 | 用“印章”体系统一标记内容性质，颜色加文字加形状三重区分 |
| 模型与 API 配置不抢主叙事 | 收进舱内“通讯台”抽屉，只在航线页和需要时出现 |

## 不做的事

- 不堆发光边框、半透明毛玻璃卡片、装饰性仪表盘。面板是不透明的纸或舱壁，HUD 底板用纯色半透明，不做模糊。
- 不用霓虹色和大面积渐变做“高级感”。高光只给一处焦点对象（`--cv-shadow-lamp`）。
- 没有授权素材时，不画具体的真实遗址、历史建筑或文物。用剪影、体块、海图符号代替，并标注“概念示意”。
- 不用模型品牌色和 Logo 代表船员身份。船员身份由职务和席位纹样表示，模型只是可配置属性。
- 概念图只用于讨论方向，不作为最终界面，也不作为史实依据。

## 色彩

三类基础材质加一个场景色：

- **墨海**（`--cv-ink-*`）：舱壁、夜海、底层表面，占画面 60–70%。
- **纸**（`--cv-paper-*`）：海图、日志、文化材料。凡是“内容本身”都放在纸上，便于长时间阅读。
- **铜**（`--cv-brass-*`）：可操作的仪器、刻度、次要按钮、等待用户选择的状态。
- **朱砂**（`--cv-cinnabar-*`）：用户的印。只用于“由用户做出决定”的主操作（确认航程、启航、提交成果）和失败状态。一屏最多一个朱砂主按钮。
- **场景色**（`--cv-scene-accent`）：由当前文明场景提供，只用于舷窗外环境、港口标记和场景内的点缀，不进入通用控件。

## 字体

- 标题：思源宋体 / Noto Serif SC。有书卷感，适配古今。
- 正文与界面：思源黑体 / Noto Sans SC。
- 数字、用量、坐标、时间：IBM Plex Mono，等宽数字，便于对比预算和实际用量。
- 场景可通过 `--cv-scene-display-font` 为场景内标题换字体，但通用界面不变。

## 材质与光照

| 对象 | 材质 | 光照 |
| --- | --- | --- |
| 船舱 | 深色木与涂漆金属的中性混合，低细节 | 一盏暖色主灯（2700K 左右）+ 舷窗透入的场景光 |
| 海图桌 | 纸面，带细网格和等深线 | 主灯直射，最亮区域 |
| 仪器 | 拉丝铜，刻度线清晰，无霓虹 | 边缘轻微高光 |
| 海面 | 低多边形加法线贴图，颜色由 `--cv-scene-water` 决定 | 场景主光 + 雾 |
| 天空 | 两色渐变（`--cv-scene-sky-top` → `--cv-scene-sky-horizon`） | 不做体积云，首版用雾控制远景 |
| 测试海域 | 灰色网格海面，无文明元素 | 中性白光 |

## 空间层次

从远到近五层，界面元素只出现在后三层：

1. **远景**：天空、雾、远处岛屿剪影（场景提供）。
2. **中景**：海面、船、港口体块（场景提供，3D）。
3. **世界标签**：港口名、碎片位置，随 3D 投影，可被遮挡。
4. **HUD**：四角固定，只显示当前任务、资源、航向和少量操作。
5. **面板与抽屉**：对话、海图、日志、通讯台。打开时 3D 降低亮度但不暂停（减少动态模式下暂停）。

## 通用船外形：宝船气势

用户每次出海看到的是同一艘船。它的气质来自明初宝船与福船：**宽体、高艉楼、多桅硬帆**。这艘船是产品的标志物，它是否“够霸气”直接决定启航页的第一印象。

**声明（必须随任何概念图与素材一起标注）**：这是**概念设计，不是考古复原**。不针对、不冒充任何一艘历史上的具体船只，也不是某一艘沉船或档案记载船只的还原。宝船的原始尺度本身在学界有争议（《明史》所载“长四十四丈四尺”等数字存疑），因此下面给的是**视觉比例，不是历史尺寸**。不使用未获授权的出土文物纹样、器物照片或他人复原图上的装饰细节。

### 外形要点

以总长 L 为基准：

| 部位 | 做法 |
| --- | --- |
| 船体 | 宽体，长宽比约 4:1；方形平艉、前端上翘，侧面为外张弧线；不做欧式尖艏 |
| 艉楼 | 占船长后 1/4，**三层**，逐层后退成阶梯，最高层带栏杆与挑檐。轮廓比任何部位都醒目——“霸气”主要来自这里 |
| 艏楼 | 占前 1/10，一层，低矮，给艏部一点厚度，不与艉楼争主体 |
| 帆 | 硬帆（横杆帆），6–8 桅；主桅居中偏前，甲板以上高度约为 2.5 倍船宽；横杆间距均匀，帆面有折线，可分层收帆 |
| 舵 | 船尾中央的大舵，舵杆与舵叶可见；不加西式船首像 |
| 船眼 | 艏部两侧各一只，白底墨瞳，略高于水线；气势与“生命感”的来源之一，不发光 |
| 栏杆与走道 | 沿舷与各楼层的连续木栏杆，给船增加层次与尺度感 |
| 隔舱节奏 | 侧面横向木分隔线，约每 1/12 L 一道，只作造型节奏，不宣称复原了隔舱数量 |

### 材质与色彩

墨木船体 + 朱漆楼层与栏杆 + 铜金配件（灯具、护角、舵首饰条）+ 米色硬帆 + 场景旗帜。

船上的朱漆与界面上“朱砂主操作”色值相近但用途完全不同：**船上的朱漆永远是材质，界面里的朱砂永远是“用户落印”**。3D 里不允许用朱漆色做可交互高亮。

船体颜色走 `--cv-ship-*` 变量（见 [tokens.css](tokens.css)），不散写在材质文件里。

### 比例建议（给 3D）

**L : B : 桅高 ≈ 4 : 1 : 2.5**（桅高指甲板以上主桅高度）。

若 L = 100 单位：

| 项 | 值 |
| --- | --- |
| 最大船宽 B | 25 |
| 主桅甲板以上高度 | 62.5 |
| 吃水 | 9–10 |
| 干舷（甲板到水线） | 8 |
| 艉楼 | 后 25，三层，每层高 5，共 15 |
| 艏楼 | 前 10，高 4 |
| 桅数 | 6–8，硬帆 3–5 面为主视觉 |

按 1:1 单位建模后整体缩放；不要按真实米数建模（会引出无法核实的“复原尺寸”主张）。

### 镜头

| 场合 | 机位 |
| --- | --- |
| 启航 | 四分之三侧影（正面偏前 20–30°），略俯 8–12°，距离约 1.8L；**整船入画，艉楼完整不被裁切**，后方是天空与雾 |
| 航行 | 斜后上方：方位角 30–40°，俯角 15–20°，距离 1.2–1.5L；船占画面宽约 1/3，前方留出目的地海面 |
| 靠港 / 进入场景 | 从航行机位推近到侧面或斜前方，船头朝向港口 |
| 减少动态 | 直接切到对应机位；不做环绕、不做推镜 |

不环绕船体、不低角度仰拍船底、不穿过帆与桅杆。

### 船是通用容器

换场景只换：`--cv-ship-banner`（默认取 `--cv-scene-accent`）、旗帜图案、帆上的点缀色，以及舷窗透进的场景光。

**船体结构、长宽比、楼高、桅数、船眼位置不变。** 允许的皮肤差异只有：帆色、旗帜、木色深浅一档。不允许为了让某个场景“更酷”而加装炮门、改尖艏、加西式船首像或改变比例。

### 夜港灯光圣经

参考 [concepts/boot-night-harbor.jpg](concepts/boot-night-harbor.jpg)（概念设计，非考古复原）：墨色海、月光冷轮廓、艉楼灯笼暖光、水线雾、水面碎光。整页只有三处亮源，其他都靠环境光托出。

#### 光源表

| # | 光 | 类型 | 色 | 强度 | 位置 | 作用 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 主光 · 月光 | DirectionalLight | `--cv-ship-lamp-cool`（#8fb6c8） | 0.55 | 左后上方，az −140°，el 42° | 勾船体、帆、艉楼挑檐的冷轮廓；不产生强阴影 |
| 2 | 辅光 · 舱口/灯笼 | PointLight × 3 | `--cv-ship-lamp-warm`（#f0b46a） | 各 1.6，衰减距离 1.2L | 艉楼三层各一盏，居中偏内 | 照亮朱漆楼层、栏杆、窗棂；这是画面最暖的一块 |
| 3 | 环境 | HemisphereLight | 上 `--cv-scene-sky-horizon`，下 `--cv-scene-water` | 0.35 | 无限远 | 托住暗部，不让船底死黑 |
| 4 | 水线反射 | 无实体灯 | 场景水色 × 1.35 | — | 船侧水线 | 由水 shader 的反射项生成，见交接清单 |

补充：
- 帆不受灯笼暖光直射（距离远），只吃月光与冷环境，因此帆比艉楼暗、比海面亮，形成三联层次：**暖艉楼 > 冷帆 > 暗海**。
- 船眼不发光，只靠材质高光和一点月光侧照，不参与 emissive。
- 甲板灯串（如有）是纯 emissive 小球，不参与照明计算，避免灯数爆炸。

#### 舷灯与灯笼的 emissive

| 项 | 值 |
| --- | --- |
| 灯笼本体 | emissive `--cv-ship-lamp-warm`，强度 1.0；内部核心小球 `--cv-ship-lamp-core`，强度 2.0，半径约 0.012L |
| 灯笼外轮廓 | 不描边、不加光晕贴片；靠曝光与色差区分 |
| 舷灯（船侧一排） | emissive `--cv-ship-lamp-core`，强度 0.8，半径 0.008L，数量以此前的圆窗节奏为准 |
| 光晕 | 只有主灯（艉楼最高层）允许一张 0.15L 的软 Sprite，不透明度 0.35，无动画 |
| 禁止 | 不做呼吸/闪烁、不做全船泛光、不给船眼加光晕 |

#### 水色与水线雾

| 项 | 值 |
| --- | --- |
| 近水色 | `--cv-scene-water` 提亮 15%，夜港以墨绿青为主（图 1 的 #1d3a38 一带） |
| 远水色 | `--cv-scene-fog` 向天空方向插值，水平线处完全融合 |
| 水线雾 | 高度 0.05L 的软雾带，颜色取 `--cv-scene-fog`，不透明度 0.35；船体入水处加密，形成“船从雾里出来”的观感 |
| 雾平面 | 一个 Y 轴贴地的雾面 + 一张半高雾墙，不用体积雾（首版成本高） |
| 水面碎光 | 只在亮源正下方（灯笼与月亮）生成竖向拉长的反射条，长度 0.3–0.8L，抖动幅度 0.004L |
| 镜面 | 见交接 §2.3：反射用一次平面反射或屏幕空间近似二选一，先给低成本版 |

#### 艉楼挑檐（用体块做，不做宫殿）

三层递退的体块 + 每层檐下一条薄挑檐，**不做完整歇山顶、不做斗拱、不做彩画**。

| 层 | 体块 | 挑檐 | 顶部 |
| --- | --- | --- | --- |
| 一层 | 长方体，占宽 0.22B，高 0.20L | 四面挑出 0.02L，厚 0.012L，端部上翘 8° | — |
| 二层 | 缩进 0.04B，高 0.18L | 挑出 0.018L，厚 0.010L | — |
| 三层 | 缩进 0.04B，高 0.16L | 挑出 0.016L，厚 0.010L | 四坡缓顶，坡度 18°，只在四角抬起 10° |

- 挑檐用薄板 + 一条铜色檐口线（`--cv-ship-trim`），不要雕花。
- 屋檐四角上翘靠顶点的轻微位移实现，不做飞檐斗拱。
- 轮廓识别靠**三层的阶梯退让 + 挑檐的水平线**，剪影在纯黑下也能认出是楼船。
- 最高层可有 1–3 个铜色脊饰，几何体（球 + 锥）即可，**不复制文物脊饰造型**。
- 窗棂：发光小矩形网格，5×8 以内，纯 emissive，不做实际几何窗格。

#### 禁止项

- 霓虹色、青色发光边框、赛博朋克配色。
- Bloom 滥用：全屏 Bloom 只允许一次后处理，阈值高到只吃灯笼核心与月亮；不做整船泛光、不做彩虹色差。
- 西式船首像、炮门、桅顶风帆旗式样、尖艏。
- 把艉楼做成宫殿或塔：不超过三层，不用完整屋顶、斗拱、彩画、匾额文字。
- 船眼发光，或把船眼做成可交互高亮。
- 用朱漆色做界面状态色或 3D 交互高亮（朱漆是材质）。
- 用未授权的文物纹样、他人复原图的雕饰。

## 通用驾驶舱与场景资源的分离

```
通用（不随场景变）              场景包（content/scenes/<id>/ 或 assets/scenes/<id>/）
├─ 船舱模型与海图桌              ├─ scene.json：名称、性质标记、出处
├─ 船（外观可换皮，结构不变）     ├─ 皮肤变量：--cv-scene-*
├─ HUD、面板、印章、状态          ├─ 天空/海面/雾参数
├─ 字体与基础色                   ├─ 港口与地标模型（或剪影）
└─ 动效规范                       ├─ 碎片图标与材料图片（附授权）
                                  └─ 可选：场景标题字体、环境音
```

换场景只换右侧，不改左侧组件。场景缺少某项素材时用通用占位（剪影、网格），并显示“素材待补”，不伪造。

| 页面 | 主视觉 | 焦点（铜灯照亮处） |
| --- | --- | --- |
| 启航 | 船停在夜港，四分之三侧影，艉楼三层剪影压住画面右侧 | “新航程”或“继续航程” |
