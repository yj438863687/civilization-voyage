# 概念设计

本目录下的预览与图片均为**概念设计**，用于讨论布局、层级与气氛，**不是最终界面，也不是考古复原**，不作为史实依据或素材依据。文字、控件与布局以上一级 Markdown 规范为准。

## 概念图

| 文件 | 内容 | 标签 |
| --- | --- | --- |
| [boot-night-harbor.jpg](boot-night-harbor.jpg) | 启航页气质参考：墨海、月光冷轮廓、艉楼灯笼暖光、水线雾、水面碎光、整船入画、艉楼压右 | 概念设计，非考古复原 · AI 生成 · 非最终界面 |
| [ship-profile.jpg](ship-profile.jpg) | 船外形分件参考：船眼、硬帆折痕与横杆、三层递退艉楼带挑檐、金色脊饰、方形平艉、中央大舵 | 概念设计，非考古复原 · AI 生成 · 仅用于外形讨论 |

两张图仅用于确认**气质与分件**，不作为建模精度、装饰纹样或色彩取值的依据：

- 不复制图中的具体雕饰、脊饰造型与纹样；建模用几何化、低细节的铜件与栏杆。
- 图中的建筑细节（完整屋顶、斗拱、彩画）**超出** ART_DIRECTION 允许范围，实现时按「艉楼挑檐（用体块做，不做宫殿）」收敛。
- 图片比例与历史尺寸无关，3D 一律按 4 : 1 : 2.5（长 : 宽 : 桅高）。
- 若这两张图来自外部生成服务，发布前需在素材清单登记生成工具、日期与使用范围。
