# 概念设计

本目录下的预览均为**概念设计**，用于讨论布局、层级与气氛，不是最终界面，也不是史实复原或素材依据。文字、控件与布局以上一级 Markdown 规范为准。

| 文件 | 内容 | 标签 |
| --- | --- | --- |
| [cockpit-preview.html](cockpit-preview.html) | 文化驾驶舱：船员席位、对话与分歧、航程任务卡、HUD 两本账与未接入状态、测试海域皮肤 | 概念设计 · 测试数据 · 场景为 AI 推荐待确认 |

打开方式：浏览器直接打开（相对引用 `../tokens.css`）；或本地 `python3 -m http.server` 后在 `docs/design/` 下访问。字体来自 Google Fonts，离线时使用系统字体回退。

扩展要求：新增预览时复用 `../tokens.css`，通过 `data-scene` 切换皮肤，页面内所有数值标注“测试”，所有场景内容标注“AI 推荐，待组员确认”。
