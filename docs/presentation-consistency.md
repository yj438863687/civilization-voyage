## 数字口径

- 金额统一为人民币。游戏和文博为单次价格，教育为每家机构每年价格。
- 首年模型：2,000×68 + 10×12,000 + 2×60,000 = 376,000元。
- 获客与直接交付成本215,200元，贡献160,800元，减固定投入240,000元，经营余额−79,200元。
- 故事包和次年续费不计入首年基准模型。
- 360,000元是全年现金规划：固定工作240,000 + 周转90,000 + 储备30,000。周转和储备不能再次从经营余额扣除。
- 首期120,000元属于360,000元之内，后续释放剩余240,000元，不另外加总成480,000元。
- 价格及机构产品是商业计划；本轮没有把它们表述为已实现销量或已签客户。

## App、API与商业计划

- 当前故事内容来自前端`voyageHistory.json`与相关叙事模块，合作支援和选择回顾在`voyageHistory.ts`实现。API保存航程world状态与记录，供刷新恢复。
- 开发中使用AI工具，与游戏运行时调用模型是不同环节。PPT中的Claude/Codex/Grok分工指制作过程。
- 模型任务接口需要明确配置；未配置时返回空模型列表和503。主线故事可以不依赖付费模型调用。
- `/trades`处理游戏测试资源；`usage.settlement`为`not_connected`，不是商业支付。
- 当前代码没有学校年费订阅、文博项目结算、真实购买或多人机构管理接口。这些是商业服务的后续交付工作，不能将游戏内交易当作真实收费接口。
- 当前后端是本地单用户形态；演讲没有将其包装成已经上线的多人机构平台或RAG服务。

## 本轮核对与复现

- `node scripts/check-original-backgrounds.mjs`：航线/年代/总结者/选择回顾与素材引用。
- `npm run build`（`apps/web`）：前端类型与打包。
- `node scripts/check-api-contract.mjs`：14个前端接口类型的字段、18组枚举与OpenAPI对应。
- 后端`app.openapi()`与`packages/contracts/openapi.json`全文比较一致。
- `python -m pytest tests/test_api.py -q`（API依赖环境、`apps/api`）：保存恢复、事务与幂等、四时代场景确认、未配置模型、任务状态及用量隔离。
- `python3 scripts/check-presentation-logic.py`：商业公式、资金拆分、App数量、双语幻灯片金额、讲稿和备注一致；时间分配合计480秒。
- `python3 scripts/export-personal-speech.py`：六页PDF文本完整，与PPT逐页备注相同。

自动化接口测试使用测试数据库及模拟上游，不会进行真实扣款；本轮未执行真实供应商调用或公网多人测试。
