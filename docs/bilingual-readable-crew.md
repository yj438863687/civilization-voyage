# 中英双语、文字清晰度与船员精修

本版保留原场景、人物互动、水上玩法、历史次序、补给与人心规则，在其上增加中英文显示和更清楚的文字。没有引入额外模型调用、联网翻译或付费服务。

## 操作

- 右上角“中文／English”可即时切换，语言选择保存在本机。
- “大字／Larger text”提高正文和标签字号，刷新后保留。
- 人物对白用空格、Enter或“下一句”推进。减少动态模式也不再快速跳过对白。
- 保留E进入、Escape返回、B船坞和WASD航行。

切换语言不重建航程，不改写故事ID、章节顺序、选择状态、历史年份、资源和升级等级。个人名字保留输入的写法；出处、作者、原始文件名等署名可以保留原文。原存档里的游戏文字在显示时翻译，存档本身不改写。

## 双语内容

菜单、海面资源与提示、角色对白、24站历史情境和选择、任务说明、港口回顾、船坞、音乐控制及配图说明均支持中英切换。也补齐练习港、桃花源暗线和八条航线的落印说明。英文情境、数值和选择方向与中文保持一致：例如拒绝可选服务仍然是拒绝，不会翻译成默认采集数据；只做围棋演示不会翻译成直接接管航行。

英文资料位于`apps/web/src/i18n/history.en.json`和`ui.en.json`。中文历史数据仍是原主线。显示层的`localize`只处理字符串，传给3D世界的几何、操作函数和存档对象保持原样。

## 清晰度

原水面浮标只绘制标题前10个字、说明前18个字；现改为1024像素纹理、完整换行及字号适配。画面另提供两项选择的文字说明，便于阅读。

资源数字放大，正文默认17px，辅助标签默认14px；大字模式进一步放大。浮动字幕使用更深的底色，缩短说明字距。手机资源、罗盘与底部操作分区排布；按钮按文字自然宽度排列，超出时横向滚动，不把英文挤在固定44px按钮里。选中项、不可购买项和退出按钮明确设置前景与背景色。

## 船员装束

保留原船员的造型与身份，调整升级装饰：

- 深靛蓝／灰青的哑光常服，窄领与小纽扣。
- 合身平顶软帽、浅色袖口和皮质腰带。
- 小型黄铜船徽，取消升级时的大块金色胸饰、旋转发光图案与夸张帽子。

船员页使用`EraDeckCrew`原模型做无遮挡预览；船体页仍展示实际船型。海上也使用同一套船员。升级费用、门槛与跨时代继承不变。

## 检查与边界

- `node scripts/check-bilingual.mjs`：1198项文字与数据检查，覆盖24站的英文情境、数字／年份／来源一致性、菜单、练习港、暗线、偏好保存及显示不改写数据。
- `node scripts/check-original-backgrounds.mjs`：8条航线的年代、总结者与升级规则。
- `scripts/check-bilingual-browser.mjs`：24站英文入口；对话中切换不重置句子与进度；语言／字号刷新保留；三级实购、手机宽度和浮标说明。
- `scripts/check-water-browser.mjs`：真实键盘跑四类任务的结算和返回；本次浮标、停船与收集成功，顺序校验验证未成功分支，仍能选择并结算；港口总结与手机显示通过。
- 构建：`VITE_API_BASE=/api npm run build --prefix apps/web`。
- 安装：`python3 scripts/install-background-build.py`，先备份前端、SQLite与场景，再同步桌面App，保留存档。

这些是定点回归，不等于24站从头连续人工通关；没有录制新Demo。中英文PPT与五人分稿仍为可编辑初版，未做完整演讲排练。
